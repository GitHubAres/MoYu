## 一、本次更新内容与实现细节

### 1. 步骤级实时流式输出缓冲区 (Workflow Live Output Buffer)
- **后端执行引擎 (app/workflow_engine.py)**：
  - 接入 chat_stream 流式传输与全局活体流式输出注册表 _live_buffers: dict[int, dict] = {}。
  - 步骤生成中实时追加 delta 增量，并在每个心跳将生成文本同步更新至活跃缓冲区，支持最大字符 MAX_OUTPUT_CHARS 保护。
  - 单步骤完成或整体任务退出时在 finally 块自动清理活跃缓冲区，防止内存泄露。
  - 针对单元测试与 Mock 打桩做了无缝自适应兼容，保证全量回归测试 100% 稳定运行。
- **工作流详情 API (app/api/workflows.py)**：
  - 在 _run_detail(db, run_id) 中动态注入 live_output，轮询接口即刻获取正在生成的实时文本、活跃步骤序号与更新时间戳。

### 2. 单步断点重试与续跑机制 (Breakpoint Resume & Single-Step Retry)
- **断点重试接口 (POST /api/workflows/runs/{run_id}/steps/{seq}/retry)**：
  - 允许作者针对流水线中某一步骤发起单步断点重跑。
  - 重置指定步骤状态为 pending，清空旧输出与审核备注，并将工作流 current_step 指针回退到该步骤，调用 workflow_engine.resume_run(run_id) 自动断点续跑后续流程。
- **前端交互增强 (static/js/pages/workflows.js)**：
  - 步骤卡片在 running 状态且存在 live_output 时呈现动态实时打字机卡片与字符计数跳表。
  - 失败步骤或待确认步骤卡片底部新增「以此步为断点重跑 / 重试此步骤」操作按钮。
