## 1. 本次更新核心功能

### 1.1 写作工作流全流程资产智能提取引擎 (pp/workflow_assets.py)
- **背景与痛点**：用户实测“写作工作流”（例如“新书开坑五连流”），发现各流程步骤输出的方案不仅有多个备选，且输出内容格式非常丰富（包含 Markdown 表格、人物小传、角色关系矩阵、分卷章节大纲、核心世界观规则等）。原有的简单正则无法识别此类结构化内容，导致最终产出未能连通到墨语各核心功能模块。
- **改进与打通**：
  - **万相谱（人物/角色/道具/势力）**：自动解析 Markdown 角色表格（| 角色 | 角色定位 | ... |）与角色设定卡（### 姓名），智能清洗表头与序号噪点，提取性格、欲望、阻碍并规范写入实体库。
  - **万相图谱（角色关系对）**：自动提取双向/单向关系表格（| 角色A <-> 角色B | 关系描述 | ... |），自动在数据库中匹配实体 ID 并规范生成可视化实体关系。
  - **故事大纲（分卷/分章节/剧情点）**：自动解析卷纲（#### 第一卷 · ...）与章节细纲（#### 第 X 章 · ...），保留标题、章纲梗概与顺序索引，同步至作品大纲系统。
  - **世界观设定（核心规则/设定笔记）**：自动解析核心设定与规则条款（### 规则一 · ...），规范同步到作品世界观设定资料库。
  - **章节正文规范导入**：支持将第 5 步试写章节自动写入目标章节的正文草稿，遵循内容安全红线。

### 1.2 前置配置与资产同步确认弹窗 (static/js/pages/workflows.js)
- **前置确认与细粒度勾选**：采纳方案或推进工作流时，系统弹出资产同步前置窗口（showAssetSyncModal），将提取出的世界观、人物角色、角色关系、故事大纲按模块分类清晰展示，支持作者自由勾选/反选要导入的项目。
- **多方案卡片独立采纳同步**：AI 输出的多个备选方案卡片均配备「选用并同步资产 (推荐)」与「选用此方案继续」双按钮，点击即可前置弹窗确认并同步导入。
- **主步骤采纳与同步联动**：主步骤下方提供「采纳并同步至作品库 (推荐)」，确认后自动向后端 /api/workflows/runs/{id}/sync-assets 发起同步并推进流程。
