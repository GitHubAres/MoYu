## 一、本次迭代目标与核心交付：全功能模块 Agent Skill 规范化与资产反哺闭环重构

依据《墨语MoYu全功能模块Agent_Skill重构与制定计划书_v2.md》，彻底解决旧版本提示词散落、命名与契约字段硬冲突（导致资产静默丢弃）、启动无脑覆写用户自定义配置、以及缺乏行级替换与反哺语义的问题。

### 1. 契约底座与字段完全对齐 (P0)
- **严格遵循权威规范**：
  - `relations`: `from_name`, `to_name`, `label`
  - `timeline_events`: `time_label`, `event`, `characters`
  - `foreshadows`: `title`, `content`, `status`
  - `outline_nodes`: `title`, `is_volume`, `parent_title`, `synopsis`
  - `chapter_synopses`: `node_title`, `synopsis`
  - `entities`: `name`, `category`, `brief`, `description`, `fields_json`
- **容灾提取与末尾容错补齐**：`extract_assets_block` 优化为提取最后一个闭合标记块，杜绝正文中引用的示例干扰；同时支持输出因 Token 上限截断时的尾部宽容容错补齐。

### 2. 路由平滑兼容与别名机制 (P0)
- **保留 `default-*` 主键**：保留 `default-continue`, `default-outline`, `default-audit` 等主键，避免工作台直接调用静默降级为旧硬编码 Prompt。
- **完善 `TASK_SKILL_MAP`**：全面支持新规划别名（如 `prose-continue`, `prose-expand`, `prose-polish`, `audit-consistency`, `audit-synopsis-distill` 等）的无死角映射。

### 3. 用户微调保护与版本化种子注入 (P0)
- **Schema 增量演进**：`skills` 表增设 `builtin_version` (TEXT) 与 `user_modified` (INTEGER)。
- **保护逻辑落地**：
  - 用户在前端编辑保存技能或挂载文件时，系统自动打标 `user_modified = 1`；
  - 启动时的 `migrate_and_seed_skills` 检测到 `user_modified == 1` 时，严禁覆写用户的 `body_md`、`description` 和挂载文件；
  - 仅对未修改的官方内置技能执行无损版本升级。

### 4. 18 项全景专业 Agent Skill 体系就绪 (P0/P1/P2)
- 沉淀了包括 `novel-timeline`（编年史时序编排）、`novel-foreshadow`（草蛇灰线暗线布网）、`novel-magic-system`（战力平衡与法则阶梯）、`prose-combat`（惊险博弈武戏拆解）、`audit-timeline`（时序因果核对）、`audit-foreshadow`（伏笔断裂与回收预警）等全矩阵技能及其配套的 `references/*.md` 方法论支持文件。
- 同步更新 `SKILL_ASSET_CONTRACTS` 资产契约映射表。
