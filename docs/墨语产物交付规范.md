# 墨语产物交付规范 (MOYU:ASSETS Deliverable Specification)

> 版本：v1.0（2026-10-09）
> 适用范围：工作流推演、AI 助手、提示词及全站结构化创作产物交付

---

## 1. MOYU:ASSETS 契约块标准格式与键清单

AI 在执行写作推演、世界观架构或大纲细化等结构化产出任务时，正文内容可自由自然排版书写。当任务涉及可沉淀入库的创作资产时，必须在回答的最末尾追加合法的 `MOYU:ASSETS` 契约块：

### 完整键清单 (7类资产键 + 1类作品信息键)
1. `work_info`：作品立项基本信息（title, genre, intro）。
2. `entities`：实体角色、道具、地点、势力与法则设定。
3. `relations`：实体之间的社交与对抗关系网络。
4. `timeline_events`：按时间标尺展开的剧情事件与登场角色。
5. `foreshadows`：伏笔埋设与暗线追踪条目。
6. `outline_nodes`：大纲树分卷与章节节点挂载。
7. `chapter_synopses`：既有大纲节点的核心剧情梗概更新。
8. `notes`：世界观概念与专有术语。

## 2. 产物归宿映射表 (Asset Destination Mapping)

所有在契约块中声明的资产，均严格映射至墨语系统的对应业务核心模块：

| 契约键 | 目标模块 / 数据库归宿 | 处理机制与契约约束 |
|---|---|---|
| `work_info` | 作品信息 (`works`) | 更新作品名称、流派分类与作品立项简介 (`intro`) |
| `entities` | 万相谱 (`entities`) | 入库实体台账；包含人物四维档案 (`fields_json`) 与自动关联登场章节 |
| `relations` | 关系图谱 (`entity_relations`) | 自动关联主体与客体实体，构建可视化人物关系图网 |
| `timeline_events` | 剧情时间线 (`timeline_events`) | 委托资产中枢 `asset_hub` 写入；支持绑定当前章节与大纲节点 |
| `foreshadows` | 伏笔看板 (`foreshadows`) | 委托资产中枢 `asset_hub` 写入；状态流转支持 `planted`/`resolved` 等 |
| `outline_nodes` | 大纲树 (`outline_nodes`) | 结构化挂载分卷与章节节点；若节点已存在且传入非空梗概则更新梗概 |
| `chapter_synopses` | 大纲节点梗概卡 (`outline_nodes.synopsis`) | 精确匹配同名大纲节点并更新其核心剧情梗概；空梗概绝不覆盖覆盖旧梗概 |
| `notes` | 万相谱设定术语 (`entities` category='lore') | 归口纳入万相谱术语库，统一台账检索与编辑 |

## 3. 边界红线与规则 (Boundary Rules)

1. **正文长文不进契约块**：
   - 契约块严禁承载大段章节正文，以避免生成超大 JSON 导致截断解析崩溃。
   - 章节正文一律走 `apply_to_chapter` 通道写入与版本沉淀。
2. **简介归口单一键**：
   - 作品简介统一采用 `work_info.intro`，全站不新增重复的 `blurb` 键。
3. **按需交付，未涉及产物键留空数组**：
   - 每个工作流步骤或手册任务仅交付其声明或关注的产物键。
   - 未涉及的键应留空数组 `[]`，不可省略键，保持契约解析的稳定与严谨。
4. **AI 内容先预览后写入**：
   - 所有契约结构化资产入库必须经过前台人工确认（弹窗多选勾选或确认二次确认），严禁静默覆盖用户已有数据。
5. **已有梗概防清空红线**：
   - 任何针对既有大纲节点的梗概更新分支，仅在传入非空 synopsis 时执行，严禁将已有内容覆盖为空。
