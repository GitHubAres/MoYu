## 1. 核心修复与优化内容

### 1.1 强制云端鉴权门禁（彻底解决首访无登录页、公网裸奔问题）
- **判定逻辑升级**：在 `app/api/auth.py` 中引入 `is_cloud_mode()`，当检测到 `HOST=0.0.0.0` 或配置了 `MOYU_CLOUD=1` 环境变量时，强制开启鉴权门禁（无需手动进数据库写入配置）；
- **门禁拦截闭环**：未初始化或未登录用户访问任何受保护 API（如 `/api/settings`, `/api/works`）直接返回 `401 Unauthorized`；
- **前端自动引导**：进入系统时，若尚未初始化管理员账号密码，自动且唯一展示 **“墨语 · 初始化设置”** 界面，彻底杜绝跳过登录直接进入书架。

### 1.2 图标字体大瘦身与渲染优化（解决加载慢与图标变成英文单词）
- **本地化字体裁剪**：将原高达 **3.9 MB** 的完整字体切片替换为包含全部 Material 图标字形的轻量优化标准 WOFF2 字体（`material-symbols-optimized.woff2`），体积缩减至 **316 KB**（瘦身 **92%**）；
- **渲染阻断优化**：在 `static/vendor/fonts.css` 中声明 `font-display: block`，彻底杜绝字体下载过程中出现“英文单词乱码”的视觉闪烁。

### 1.3 移动端布局防挤压与安全区保护（解决文字溢出与内容裁切）
- **iOS/Android 全局安全区注入**：在 `static/css/app.css` 中配置 `env(safe-area-inset-top)` 与 `env(safe-area-inset-bottom)`，让悬浮 FAB 按钮及顶栏自动避开灵动岛和底部手势横条；
- **顶栏小屏自适应收敛**：在屏幕宽度 `< 640px` 时，将顶栏繁琐的“今日字数 / 5,000 / 全书累计”统计信息移出小屏顶栏（书架 Dashboard 与写作区本身已有大字统计），为汉堡菜单、保存状态与核心操作腾出充足空间，彻底消除文字换行与挤出屏幕问题。
