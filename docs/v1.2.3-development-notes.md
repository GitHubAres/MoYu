## 1. 核心需求与交付内容

依据多端与生产级部署规划，在**严格保证桌面端体验 100% 零回归、核心业务逻辑与 API 接口完全兼容**的前提下，完成以下两大工作线交付：

### 1.1 VPS 生产环境部署能力补齐（工作线 B）
- **环境变量解耦**：
  - `run.py` 改造为优先读取 `HOST`（默认 127.0.0.1，容器内 0.0.0.0）与 `PORT`（默认 8321）；
  - `app/paths.py` 支持 `MOYU_DATA_DIR` 环境变量覆盖数据存储根目录；
  - `/api/health` 扩充健康检查信息字段（保持原有契约，无缝适配 Docker healthcheck 与外部探活）。
- **轻量生产级 Docker 方案**：
  - 新增 `Dockerfile`（基于 `python:3.11-slim` 多阶段构建，非 root 用户 `moyu` 运行，内置健康探活，大小约 150MB）；
  - 新增 `.dockerignore`，排除无关环境、测试文件及敏感数据；
  - 新增 `docker-compose.yml`，集成卷持久化 `./data:/app/data`、健康检查与重启策略。
- **裸机生产部署配套**：
  - 新增 `deploy/nginx/moyu.conf`：具备标准代理头透传、静态文件 Gzip 压缩与 **`proxy_buffering off;`（关键支持 AI 流式输出不卡顿）**；
  - 新增 `deploy/systemd/moyu.service`：Linux 原生守护单元，支持故障自愈重启；
  - 新增开箱即用的完整部署文档 `docs/deployment.md`。

### 1.2 多端与移动端响应式进阶规范（工作线 A）
- **触控热区基线**：在 `static/css/app.css` 中注入 `.touch-target` 规范（`min-width: 44px; min-height: 44px`），保障触屏无障碍可点；
- **流式字号规范**：引入 `.fluid-title` 与 `.fluid-body` 基于 `clamp()` 的动态伸缩字号；
- **小屏防撑裂保底**：新增针对 `max-width: 640px` 的卡片与表格堆叠流动样式（`.sm-stack`, `.sm-full`），杜绝全屏横向滚动条。
