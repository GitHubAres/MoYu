# 墨语 MoYu v1.7.6 开发进展说明与发布记录

> **版本**：v1.7.6  
> **更新日期**：2026-10-03  
> **性质**：Skill 体系文案统一 + 经典面板预存 bug 修复 + 旧提示词死代码清理 (Patch Release)

---

## 1. 更新背景

用户实机反馈：写作工作台「修撰使精调选项」抽屉中的「提示词模板」疑似与 Skill 功能重复。经核实，该下拉底层自 v1.6.0 起已是 Skill 体系（数据源 `/api/skills`，选中项作为 `skill_id` 传入 `/api/chat` 与 `/api/ai/generate`），与快捷任务按钮（续写/扩写/缩写/改写）是「任务 × 技能」组合关系，功能上不重复；但存在文案滞后、经典面板控件被抢占、旧提示词死代码三处收口项。

---

## 2. 改动实施

### 2.1 工作台设置区重构（`static/js/pages/workbench.js`）

- 将「长度 / 候选 / 写作技能」三个控件合并为单一实例 `settingsBlock`；
- `syncAiPanelMode()` 随聊天/经典模式在两个挂载槽之间搬移：经典模式挂入经典面板「任务控制」卡，聊天模式挂回「修撰使精调选项」抽屉；
- **修复预存 bug**：原实现将 `skillSelect`/`lenSeg`/`candSeg` 重复 append 到经典面板与抽屉两处，DOM 节点被后一次 append 抢走，导致经典多候选面板只剩「提示词模板/长度/候选」三个孤儿标签、控件不可见不可调；
- 文案统一：「提示词模板」→「写作技能」；下拉首项「默认技能 (内置)」→「自动匹配内置技能（推荐）」；
- 下拉下方新增说明「未选择时按任务自动匹配内置技能」与「管理技能 →」直达链接（`#/skills`）。

### 2.2 旧提示词体系死代码清理

- 删除 `static/js/pages/prompts.js`（自 v1.6.0 起未被 `index.html` 加载，`#/prompts` 已由路由重定向至 `#/skills`）；
- 删除 `app/api/prompts_api.py`（未挂载，测试已断言 `/api/prompts` 返回 404）；
- `app/features.py`：删除 `PromptLibrary` 类、`_PromptIn`、`_prompt_library` 与 `get_prompt_library()`；
- `app/db.py`：schema 移除 `CREATE TABLE prompts`；老库升级路径不受影响（`migrate_and_seed_skills` 第 3 步有 `sqlite_master` 存在性检查，仍可读取老库 prompts 表完成迁移）；
- `tests/conftest.py` 注释同步；`/api/prompts` 404 退役断言保留且继续通过。

### 2.3 文档与版本同步

- `app/version.py`：`1.7.5` → `1.7.6`；`tests/test_deploy_and_env.py` 断言同步；
- `static/index.html`：`workbench.js` 缓存戳 → `?v=1.7.6`；
- `docs/PRD-本地版.md`：Skill 市场路由更正为 `#/skills`，3.13 节「提示词管理」重写为「Skill 市场」真实功能描述；
- `AGENTS.md`、`README.md`：版本号引用同步为 `1.7.6`，README 更新表新增 v1.7.6 行；
- 新增本文档 `docs/v1.7.6-development-notes.md`。
