# 「墨语」AI 小说写作工具｜前端产品需求文档

- 版本：v0.2（优化稿）
- 日期：2026-09-26
- 文档状态：待产品、设计与研发评审
- 依据：用户提供的《AI小说写作工具-核心功能思维导图》（8 大模块、42 项功能）及原 PRD v0.1
- 范围：面向 Web 桌面端与移动端的产品体验和交互需求；不规定技术选型、服务端实现与模型方案

---

## 1. 产品定义

「墨语」面向网文作者、长篇创作者及写作爱好者，提供从灵感整理、作品规划、正文创作、设定管理到作品导出的连续创作体验。产品以编辑器为中心，AI 是可控的创作助手：帮助作者推进写作、整理上下文和检查设定，作者始终决定哪些内容进入作品。

**产品气质：**安静、沉浸、有文气。界面减少打断，突出正文与当前任务；AI 内容与作者正文清晰区分，所有 AI 修改先预览、再由用户确认。

### 1.1 产品目标

1. 作者能快速回到上次创作位置，并在写作时方便地查阅目录、设定和前情。
2. 作者能针对选区或章节调用 AI，比较结果后选择性采纳，不丢失原文。
3. 作者能结构化管理作品大纲、人物、设定和伏笔，减少长篇创作中的遗忘与矛盾。
4. 作者能在桌面端完成主要创作，在移动端可靠地阅读、记录灵感和处理轻量任务。

### 1.2 非目标与边界

- 本产品不替作者自动发布作品；发布平台接入、定时发布及账号授权须单独评估，未接入时仅提供导出与存稿管理。
- “设定一致性检查”“文风学习”“AI 封面/立绘”等结果是辅助建议，不承诺完全准确，也不得静默修改正文或设定。
- 本 PRD 不确定具体模型、云同步实现、加密算法、收费价格及第三方平台能力。

## 2. 用户与优先级

| 用户 | 主要任务 | 首要体验要求 |
|---|---|---|
| 网文连载作者（核心） | 持续更新、续写、拆章、维持设定一致 | 快速进入章节、写作不中断、AI 结果可控 |
| 长篇/独立创作者 | 规划故事、维护人物与世界观、追踪伏笔 | 结构清晰、关联可查、历史可恢复 |
| 新手/兴趣作者 | 从想法发展到大纲和正文 | 有明确起步路径、生成过程可理解 |
| 进阶创作者 | 调整提示词、上下文与模型 | 配置透明、结果可比较、用量可查 |

### 2.1 优先级定义

- **P0（首发核心）**：缺失会阻断核心创作闭环，必须进入首发范围。
- **P1（增强体验）**：首发后优先完善，可先以简化形态交付。
- **P2（待验证）**：依赖外部平台、复杂生成能力或用户需求验证，先不承诺上线时间。

| 能力 | 优先级 | 首发建议 |
|---|---:|---|
| 书架、作品/卷/章管理、编辑器、自动保存、版本恢复 | P0 | 完整支持 |
| AI 续写/扩写/改写、结果预览与采纳、停止与重试 | P0 | 支持单次生成及多候选基础比较 |
| 角色与设定条目、章节关联、搜索 | P0 | 先支持列表与详情，不要求复杂图谱 |
| 大纲与章节映射 | P0 | 先支持树形大纲与章节草稿 |
| 导入、导出基础格式 | P0 | TXT、DOCX；其余格式按实现评估 |
| 灵感便签、移动端轻量记录 | P1 | 移动 Web 适配后交付 |
| 剧情泳道、伏笔看板、人物关系图谱、时间线 | P1 | 逐项验证使用价值 |
| 自定义工作流、Few-shot、按任务多模型路由 | P1 | 先提供模板和基础参数 |
| AI 封面/立绘、平台定时发布、发票 | P2 | 依赖能力与商业模式评估 |

## 3. 核心任务流程

### 3.1 首次创作

创建作品 → 填写书名及可选简介/类型 → 进入空书架或工作台 → 新建卷/章或导入正文 → 可选创建角色/设定 → 开始写作。引导可跳过，并可从帮助入口再次打开。

### 3.2 日常续写

书架点击“继续写作” → 打开最近章节并恢复光标位置 → 查看前情与相关设定（若有） → 输入正文或对选区发起 AI 操作 → 预览并采纳所需内容 → 自动保存 → 返回书架时更新字数与最近编辑时间。

### 3.3 大纲生成到正文

创建/编辑大纲节点 → 选择“生成章节草稿” → 查看生成设置及将使用的上下文 → 生成候选 → 用户采纳到草稿区 → 用户编辑并保存。采纳不得覆盖已有正文；已有正文时须明确选择插入位置或替换，并提供原文恢复方式。

### 3.4 设定检查

选择作品或章节发起检查 → 确认检查范围 → 查看运行状态 → 浏览问题及证据引用 → 跳转原文/设定 → 忽略、标记待处理或手动修正。检查结果是建议，不直接修改内容。

## 5. 功能需求

### 5.1 书架（P0）

- 显示作品封面或默认占位、书名、总字数、最近编辑时间及最近打开章节。
- 支持新建、重命名、归档/删除、导入作品；删除前说明影响并提供恢复期限/回收站规则（规则待业务确认）。
- 支持按书名搜索和最近编辑排序；“继续写作”打开最近编辑章节。
- 首次使用提供“创建作品”“导入作品”两个明确入口及可跳过的新手引导。
- 灵感便签作为 P1 能力；若首发提供，需支持创建、编辑、删除及关联到作品/章节。

### 5.2 创作工作台（P0）

**布局：**桌面端由目录区、编辑区、AI/上下文侧栏组成；侧栏可收起，编辑区优先保持足够宽度。用户可调整面板显隐，布局状态按用户偏好保存。

**目录区**

- 以作品 → 卷 → 章的层级呈现；支持新增、重命名、移动、排序和删除。
- 章节状态至少区分“草稿”和“已完成”；如提供“已发布”，须明确它表示用户手动标记，不意味着平台已发布。
- 移动/删除章节后，相关大纲、设定引用和正文内容不得无提示丢失；确认信息需指出受影响内容。

**编辑区**

- 支持正文输入、撤销/重做、标题/段落格式、查找替换和字数统计。首发只承诺一种稳定编辑模式；Markdown/富文本双模式需定义互转规则后再上线。
- 支持章节字数、作品累计字数和用户自设目标进度；统计口径（是否含空格、标点、标题）在界面帮助中说明。
- 自动保存状态显示“正在保存 / 已保存 / 保存失败 / 离线待同步”，失败时提供重试入口。
- 专注模式隐藏非必要面板，可调整主题、字号及行宽；退出后恢复原工作区。
- 选区工具提供续写、扩写、缩写、改写润色及描写建议；结果以差异预览/暂存内容展示。

**AI 助手**

- 用户可选择任务、生成长度（简/中/长或字数范围）、候选数量及可用的风格指令。
- 发起前以简明方式展示本次上下文来源：当前章节、前文摘要、相关设定等；可查看并取消不需要的上下文项。
- 生成过程中显示进度/流式内容、停止操作及错误状态。停止后已生成内容保留在候选区。
- 候选支持整体采纳、复制、重试；部分采纳作为增强项，需定义段落边界和插入位置。
- 采纳写入后支持撤销，并进入版本历史。已有正文的替换操作必须二次确认。
- 前情摘要可查看、重新生成和手动编辑；AI 不得把摘要自动当作已确认设定。

### 5.3 大纲（P0 基础）

- 支持作品/卷/章节层级的大纲节点，节点可编辑标题、梗概和状态。
- 支持调整顺序及将大纲节点关联到章节；从节点创建章节时保留关联。
- AI 生成或扩写大纲前可选择范围与上下文，结果先进入预览态。
- 剧情线泳道、情节点子推荐及拖拽看板列入 P1。

### 5.4 设定库（P0 基础）

- 提供角色、地点、势力、物品、规则/术语及自定义分类；每条设定至少有名称、正文、更新时间和可选标签。
- 支持新增、编辑、搜索、归档/删除；可从章节关联设定，详情中显示关联章节。
- 角色模板可含姓名、身份、性格、背景、目标与变化；空字段不强制填写。
- AI 自动识别术语、生成关系图、时间线及自动矛盾检查列入 P1；用户主动发起的一致性检查需显示范围、引用证据、置信提示和忽略/处理状态。
- 设定内容默认由用户确认；自动提取结果进入“待确认”，不可直接写入正式设定。

### 5.5 版本历史与恢复（P0）

- 按章节列出自动保存记录和用户手动快照，显示时间、来源和可读标签。
- 支持查看两个版本的差异；恢复前展示将替换的当前版本及目标版本。
- 恢复操作可撤销，且恢复前当前正文自动留存为一个版本。
- 自动保存与历史快照的频率/保留期限属于产品策略配置项，需在上线前确定。

### 5.6 导入与导出（P0 基础）

- 导入前显示支持格式、文件大小限制及导入后的章节拆分预览；失败时保留原文件并说明原因。
- 导出可选择全书、卷或章节；导出前提供目录/标题格式预览。
- TXT、DOCX 为首发建议；PDF、EPUB 及各平台排版适配需验证格式质量后承诺。
- 导出任务显示排队、处理中、完成或失败；完成后可下载，失败可重试。
- 平台账号授权、定时发布及自动发布为 P2，单独评估合规、权限和平台接口。

### 5.7 设置、同步与隐私（P0 基础）

- 支持主题、编辑器字号/行距、自动保存偏好、快捷键说明。
- 云同步需显示同步状态、最后同步时间及冲突处理入口；冲突时不得静默覆盖任一端内容。
- 提供账户数据导出及删除入口的产品说明；作品加密、本地模型和私有化部署在能力确认前不作为已交付功能宣传。
- 模型与 Token 用量统计列为 P1；展示估算时标明统计口径和可能的延迟。

## 6. 交互与状态规则

### 6.1 AI 内容安全规则

1. 生成内容必须与用户正文在视觉和操作上区分，默认处于暂存/预览态。
2. 任何采纳、替换、批量写入均可撤销；原文进入版本记录。
3. 编辑选区的改写以差异方式呈现，用户明确确认后才替换。
4. 生成失败、停止、切换章节或关闭面板时，已产生的候选内容不应无提示消失。
5. 系统说明上下文使用范围，并允许用户在发起前移除可选上下文。

### 6.2 保存、离线与冲突

- 输入停止约 2–3 秒后触发保存；界面不得仅依赖延迟保存作为唯一保护，导航离开时仍需处理未保存状态。
- 保存失败时保留本地输入并持续提示，提供重试；断网恢复后尝试同步。
- 多端同一章节发生冲突时，保留两个版本并让用户选择或手动合并，不静默覆盖。

### 6.3 加载、错误与反馈

- 超过 300ms 的操作提供可见反馈；页面首屏使用骨架占位。
- AI/导出/检查等长任务可取消或在后台继续；状态可从任务入口重新查看。
- 超时后提供重试和错误说明；重试不得重复写入已经成功的内容。
- 拖拽失败、保存失败等操作反馈说明发生了什么，并给出可执行的恢复动作。

### 6.4 快捷键与命令入口

- 常规编辑快捷键遵循操作系统惯例；产品级快捷键允许在设置查看，并避免与输入法/浏览器常用快捷键冲突。
- 全局搜索可检索作品、章节和设定；命令面板中的动作需有明确名称和执行结果。
- 原稿中的 Ctrl+/、Ctrl+K、Alt+Space 作为候选方案，最终以跨平台冲突检查后的快捷键表为准。

## 7. 视觉与内容设计

- **方向：**东方文气与现代简洁结合，以纸感、留白和低饱和色构建安静的写作环境。
- **主色建议：**黛青/墨蓝为基础色；朱砂色用于强调操作或重要状态。各功能区辅助色需满足文本对比度，不仅靠颜色区分状态。
- **AI 标识：**AI 生成或建议内容始终有清晰文字标签；渐变/水墨效果仅作辅助，不能替代标签。
- **字体：**界面使用清晰的系统无衬线字体；正文可选宋体类字体。字体不可用时提供合理回退。
- **主题：**浅色为默认；深色和纸张色作为用户可选主题。确保表单、选区、错误提示和 AI 暂存态在各主题下可辨识。
- **圆角、阴影与纹理：**轻量使用，避免干扰长时间阅读与输入；纹理不应用于正文编辑区域的高对比背景。
- **无障碍：**键盘可达、焦点可见、图标有文本/辅助说明、重要状态不只用颜色传达。

## 8. 空状态与引导

所有空状态包含简短说明和一个主要下一步；次要动作不与主操作争夺注意力。

| 场景 | 空状态及动作 |
|---|---|
| 空书架 | 说明可创建或导入作品；主按钮“创建作品”，次按钮“导入作品” |
| 新章节 | 提供“开始写作”“粘贴正文”；AI 初稿作为可选操作 |
| 空设定库 | 按分类展示新建入口及可选示例模板；示例可整体清除 |
| 无版本记录 | 说明编辑后会生成记录，并链接到版本策略说明 |
| 搜索无结果 | 展示已搜索范围、修改关键词建议及可用的新建入口 |
| 无图谱数据 | 说明需要的最少角色/关系数据，并提供跳转设定库操作 |

首次引导最多 3–5 步，支持跳过、关闭和重新打开；不强制用户先完成设定才能开始写作。

## 9. 移动端需求

- 移动端优先保障阅读、灵感记录、查设定和采纳 AI 结果；复杂大纲编排与高强度写作以桌面端为主。
- 工作台改为单栏，使用目录、正文、AI 等清晰入口切换；切换不丢失编辑状态。
- 编辑器支持轻量编辑、查找、撤销和选区操作；长按菜单与系统选择行为兼容。
- AI 候选纵向呈现，可停止生成、预览并采纳；采纳前能看清写入位置。
- 关系图谱支持缩放和平移；若交互不适合小屏，应提供列表视图替代。
- 触控目标建议不小于 44×44 CSS 像素；处理安全区、软键盘遮挡和误触刷新。
- 同步冲突与离线状态在移动端同样可见且可处理。

## 10. 首发验收标准

1. 用户可创建或导入作品，创建卷/章并进入编辑；重新打开后可回到最近章节。
2. 在不少于 10,000 中文字的章节中，输入、滚动、查找与基本格式操作保持可用；性能目标由设计/研发评审补充量化指标与测试设备。
3. 自动保存状态可见；模拟保存失败或断网时，已输入内容保留，恢复后可重试同步。
4. AI 续写/改写内容先显示在独立预览区；未确认前不改变正文。停止生成后已生成内容仍可查看。
5. 用户采纳 AI 内容后可撤销，且可从版本历史找回采纳前内容；替换现有正文前明确提示影响范围。
6. 设定条目可创建、编辑、搜索，并能从章节查看关联设定；AI 检查结果能定位到引用原文或明确标注无引用依据。
7. 用户可查看章节版本差异并恢复；恢复前的正文仍可找回。
8. TXT、DOCX 导出范围与目录结构符合用户选择；导出失败时显示原因并允许重试。
9. 移动端可阅读作品、完成轻量编辑、记录灵感、查设定并采纳 AI 候选；保存与同步状态可见。
10. 键盘焦点、错误提示和主要状态在浅色、深色主题下均可辨识，关键操作不依赖颜色单独表达。
