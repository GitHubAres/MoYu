# Part A · 墨语技能重构 Codex 开发指引与全局红线

## A1 读档与工程背景 (依据 AGENTS.md §9 + §10)
1. **读档第一法则**：本任务必须首先确认当前版本状态为 **v2.2.0**，测试基线以 `pytest --collect-only` 实测为准（当前为 **220 tests**）。严禁引用已归档停维护的 `docs/development-plan.md`。
2. **测试基线红线**：所有修改后，运行 `.venv/Scripts/python -m pytest -q` 必须保持 **220 passed 零回退，测试数量只增不减**。
3. **测试数据隔离**：严禁污染真实 `data/` 目录，自动化测试必须使用隔离临时路径。

## A2 技能重构专项工程红线 (违背即驳回)
1. **技能名称 `name` 绝对冻结**：
   - `features.py:103-125` 中的 `TASK_SKILL_MAP`、`workflows.py` 工作流 seed 以及 API 层均硬依赖现有的 13 个内置技能名：
     `default-continue`, `default-expand`, `default-shorten`, `default-rewrite`, `default-outline`, `default-audit`, `default-analysis`, `novel-premise`, `novel-world`, `novel-cast`, `novel-scene`, `novel-forge`, `de-ai-tone`。
   - **严禁新增、删除或修改 `name` 字符串**。
2. **输出格式纯净度与 Diff 视图契约**：
   - 行文类技能（`default-continue`, `default-expand`, `default-shorten`, `default-rewrite`, `de-ai-tone`）必须遵守墨语核心原则：**直接输出正文，禁止自作聪明输出任何解释性文字、开场白、结尾总结或 Markdown 差异表格**。
   - 墨语前端编辑器拥有原生的 Git-style 差异比对与版本撤销渲染器，混入非正文字符会导致 Diff 崩溃和脏数据写入。
3. **输入参数契约标准插值**：
   - 技能必须正确支持并声明三大核心插值占位符：`{{context}}` (前文上下文), `{{selection}}` (选区正文), `{{instruction}}` (用户补充指令)。
4. **数据库 Seed 增量覆盖机制**：
   - 墨语在启动初始化时（`db.py:2507` 附近的 `seed_builtin_skills`）会以 `ON CONFLICT(name) DO UPDATE` 机制将代码库中的内置技能同步写入 `skills` 表。
   - 重构必须在代码源头（`app/builtin_skill_data.py` 和 `app/db.py`）落地，确保重启和全新安装后内容永不丢失。
5. **朱雀等工业级 AI 检测对抗法则**：
   - **低 PPL 破除**：通过跨域通感、低频实词、意象错位提升条件概率预测难度；
   - **低 Burstiness 破除**：采用“3-20-3”句长节奏（1~5字极短句与40~60字长句高频交替，离散系数 CV ≥ 0.75）；
   - **零逻辑连词**：彻底禁止“与此同时/不仅如此/然而/事实上”等书面过渡词，全部由动作与物理事件接管；
   - **零总结说教**：剥离段末心理感悟和章节收尾的假大空升华；
   - **物理化反射 (Show, Don't Tell)**：情绪降维为生理表征（汗、瞳、牙、息、肌）。

# Part B · 分批次开发规划与任务书

为降低工程风险并确保每一步均有测试回归护航，重构任务拆分为四个独立递进批次（Batch 1 ~ Batch 4）：

```
[Batch 1: 去AI味三剑客] ──► [Batch 2: 微观写作与剪辑] ──► [Batch 3: 开坑五连流升级] ──► [Batch 4: 质检总控与全量验收]
(de-ai-tone, continue,       (expand, shorten)             (premise, world, cast,         (audit, analysis, forge,
 rewrite)                                                   outline, scene)                pytest 220+ 回归)
```

---

## 批次一 (Batch 1)：去AI味三剑客与行文底座重构 (P0 核心层)

### 任务清单：
1. **重构 `de-ai-tone`（去AI味·人味还原）**：
   - **目标**：彻底改造为朱雀/知网对抗专用引擎。
   - **规范要点**：
     - 去除原有的泛文体折中设计，以网络文学与现代通俗小说为核心基准；
     - 重构执行管线：骨架破坏 ➔ 生理反射替换 ➔ 3-20-3 句长极化 ➔ 零逻辑词切断；
     - 严正修正输出协议：直接输出改后正文，废除原先生成 Markdown 表格说明的违约行为。
2. **重构 `default-continue`（续写·顺延文势）**：
   - **目标**：从 334 字简陋提示词全面升级为 2,000+ 字工业级长篇网文续写引擎（全系统任务兜底）。
   - **规范要点**：
     - 首句动作切入：禁止复述前文，直接以物理变动或对白起笔；
     - 注入微观反检测指纹：句式不对称化、禁止成语三连、禁止抒情升华；
     - 卡点断章机制：末尾强制制造信息差、危机切面或行动停顿，留下强钩子。
3. **重构 `default-rewrite`（改写润色·字句打磨）**：
   - **目标**：强化文学画面张力与叙事节奏微调。
   - **规范要点**：
     - 与 `de-ai-tone` 形成组合拳，专注于语序动态化、画面聚焦感调节与冷峻白描。

### 验收与门禁：
- `app/builtin_skill_data.py` 与 `app/db.py` 同步写入；
- 新增单元测试 `tests/test_skills_refactor_batch1.py`：测试三剑客解析渲染、无 Markdown 废话、占位符完整替换；
- 全量回归 `pytest -q` 保持 220+ 通过。

## 批次二 (Batch 2)：微观场景动作展开与电影级快剪 (P0 写作台)

### 任务清单：
1. **重构 `default-expand`（扩写·充实细节）**：
   - **目标**：破除“形容词与心理活动注水”，重构为“动作与感官张力扩张”。
   - **规范要点**：
     - 建立微观阻力模型：增加角色行动时的空间障碍、道具触感、环境光影变动；
     - 对话展开：增加潜台词微表情、打断与非对等交锋。
2. **重构 `default-shorten`（缩写·凝练取舍）**：
   - **目标**：从公文式压缩升级为“网文电影快剪”。
   - **规范要点**：
     - 剔除过渡交代与解释性独白；
     - 提纯因果骨架与高潮爆发点，将松散段落提炼为短促有力的连环节奏。

### 验收与门禁：
- 写作台扩写与缩写按钮在模拟数据下输出纯净正文；
- 全量回归 `pytest -q` 保持零回退。
