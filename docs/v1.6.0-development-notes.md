## 1. 架构升级概述

本版本将原"提示词中心"（纯文本模板模式）全面升级为标准的 **Agent Skill 市场**，以 **元数据（name/description）+ 核心指令（SKILL.md 正文）+ 挂载资源（scripts/references/assets）** 为核心架构：

1. **结构化 Agent Skill 契约**：
   - `SKILL.md` 包含规范 YAML frontmatter（`name` 与 `description`），正文为 Markdown 核心指令；
   - 挂载资源白名单分类：`references/`（供模型内联读取的文档）、`scripts/`（可执行代码清单）、`assets/`（产出素材清单）；
   - 采用安全容量与路径约束：单文件 ≤ 200KB，资源总容量 ≤ 1MB，禁止绝对路径与 `..` 路径穿越。
2. **AI 写作链路重构与死占位符修复**：
   - 服务端实现统一的 `build_skill_system_prompt()` 编排装配器；
   - 彻底修复旧版模板中 `{{context}}` / `{{selection}}` / `{{instruction}}` 占位符从未替换的残留问题，动态精准替换；
   - 被替换的字段不再在下游 User 消息中重复堆叠，大幅精简 Prompt 上下文；
   - `references/` 规范文档自动内联进 System Prompt（带 token 截断与 `[内容过长已截断]` 标记），`scripts/` 与 `assets/` 输出规范清单。
3. **分发与安全格式**：
   - 支持 `.skill`（标准 zip 归档）一键打包导出与导入安装；
   - 内置安全校验与命名冲突重命名机制（自动改名 `<name>-imported`）。
4. **旧数据平滑迁移与接口退役**：
   - 首启自动执行 `migrate_and_seed_skills()`：旧 `prompts` 自定义模板自动迁移为 `source='migrated'` 的 Skill，原内置模板对应升级为 6 个规范命名（`default-continue` 等）的内置 Skill；
   - 旧版 `/api/prompts` 接口正式退役（返回 404），前端 `#/prompts` 自动平滑重定向至 `#/skills`。
