## 1. 版本概述

墨语 MoYu 正式发布 **v2.2.0** 版本。本版本重磅推出**「热点雷达 (HotRadar)」与创作模块的双向互通体系**（M1–M9），为网文创作者提供起点、番茄、晋江三大主流网文平台的实时爆款榜单追踪、多维度题材对比、一键立项灵感草稿生成、资产中枢沉淀以及工作流「灵感采集」节点装配能力。

---

## 2. 新增与变更模块及路由

### 2.1 后端服务与路由接口
- **数据持久层 (`app/db.py`)**：
  - 新增 `hot_topics` 数据表及 `idx_hot_topics_platform_rank`、`idx_hot_topics_collected` 索引，支持热榜数据持久化与收藏状态维护。
- **热榜抓取与调度服务 (`app/services/hotradar_fetcher.py`, `app/services/hotradar_scheduler.py`)**：
  - `BaseRankFetcher`、`QidianRankFetcher`、`FanqieRankFetcher`、`JjwxRankFetcher` 实现主流榜单规范化解析；
  - 调度器 `cleanup_expired_topics()` 自动淘汰 7 天前未收藏记录，已收藏条目永不过期；
  - 手动触发刷新 API 增加防刷冷却时间保护。
- **业务 API 路由 (`app/api/hotradar.py`)**：
  - `GET /api/hotradar/list`：多条件筛选与榜单分页查询（支持平台、题材标签与仅看收藏过滤）；
  - `POST /api/hotradar/refresh`：手动触发全网热点拉取（带冷却防护）；
  - `POST /api/hotradar/collect`：切换收藏状态，支持联动 `asset_hub` 沉淀创作灵感资产；
  - `POST /api/hotradar/to-outline`：基于热点生成 P0 立项草稿预览建议（严格预览返回，不静默入库）。
- **双向互通链路**：
  - **M6 AI 提示词注入 (`app/features.py`)**：新增 `get_top_hot_genres()`；在 `build_skill_system_prompt()` 中设置触发词守卫（仅在立项/选题/大纲等策划任务时条件式追加全网热门题材 TOP10，正文续写/扩写任务零副作用）；
  - **M7 工作流节点联动 (`app/api/workflows.py`, `app/workflow_engine.py`, `app/services/context_service.py`)**：`INPUT_MODES` 扩充 `"hotradar"` 模式，上下文装配服务支持 `assemble_hotradar_summary_block()`；
  - **M8 资产中枢沉淀 (`app/services/asset_hub.py`)**：新增 `record_hot_topic_asset()`，收藏热点转化为合规 `MOYU:ASSETS` 契约块（未涉及键留空数组 `[]`，指定作品时入库为 `lore` 设定）。

### 2.2 前端单页应用与交互页面
- **热点雷达页面 (`static/js/pages/hotradar.js`)**：
  - 采用 Literary Minimalist Ink 设计风格，提供多平台 Tab 切换、题材胶囊过滤与收藏状态切换；
  - 「我的题材 vs 全网热点」蓝海对比看板；
  - 一键立项灵感模态弹窗，作者二次确认后才创建作品。
- **工作流配置页面 (`static/js/pages/workflows.js`)**：
  - 新增「灵感采集（全网热点摘要）」步骤输入模式选项。
- **导航与资源索引 (`static/index.html`)**：
  - 挂载热点雷达导航项与静态资源版本缓存戳更新 (`?v=2.2.0`)。

## 4. 墨语预设技能体系全面重构与去AI味深度升级交付 (Batch 1 ~ Batch 4)

依据《墨语预设技能体系重构开发指引与任务书》要求，完成墨语全量 13 个预设官方 Skill (`source='builtin'`) 的深度重构与代码级持久化：

### 4.1 核心攻防模型落地与执行批次
1. **批次一 (Batch 1: 去AI味三剑客与行文底座)**：
   - `de-ai-tone`：全面改造为朱雀/知网对抗专用引擎，注入困惑度突刺 (PPL Booster)、突发度节奏极化 (Burstiness 3-20-3)、零逻辑连词 (Zero Connectives) 与生理反射法则 (汗·瞳·牙·息·肌)，确立纯正文输出契约。
   - `default-continue`：升级为 700+ 字工业级长篇网文续写提示词，首句物理动作切入，卡点断章悬念收尾。
   - `default-rewrite`：精修文学画面张力，严格继承校准三原则与消痕打磨。
2. **批次二 (Batch 2: 微观场景动作展开与电影级快剪)**：
   - `default-expand`：建立物理阻力与微动作感官展开模型，杜绝套路化形容词注水。
   - `default-shorten`：提纯因果骨架，实现网文电影级快剪。
3. **批次三 (Batch 3: 宏观策划与新书开坑五连流体系升级)**：
   - `novel-premise`：深度融入黄金三章卖点法则与商业情绪价值供给类型定位。
   - `novel-world`：强化超凡代价体系 (Magic System Cost) 与稀缺利益阶梯矛盾。
   - `novel-cast`：植入即时欲望驱动与反派自洽逻辑，主要角色定制反差说话癖好。
   - `default-outline`：建立“三章一小波峰、五章一大高潮”推进骨架与卷末卡点断章设计。
   - `novel-scene`：细化分场进出点情绪位移，严密对接墨语资产中枢 (asset_hub) 契约（伏笔与时间线）。
4. **批次四 (Batch 4: 质检总控与全量综合验收)**：
   - `default-audit`：专项核查战力膨胀崩塌、人设吃书与时间线逻辑倒挂。
   - `default-analysis`：十维体检最低分维度就地给出高可操作性去AI味示范。
   - `novel-forge`：端到端七段创作门禁硬核拦截，禁止带病推进。
   - 新增专项测试 `tests/test_skills_refactor_batch1.py`，全量回归保持 **224 passed 100% 全绿通过**。
