# 墨语 MoYu v1.7.7 开发进展说明与发布记录

> **版本**：v1.7.7  
> **更新日期**：2026-10-03  
> **性质**：修撰使思考过程可视化 (Feature Release)

---

## 1. 需求背景

用户反馈：使用 AI 续写等功能时，AI 对话框只显示生成结果，看不到中间过程，希望像 Kimi Agent 那样展示 agent 任务思考过程。

---

## 2. 改动实施

### 2.1 后端：思考步骤 SSE 事件（`app/api/chat.py`）

- `app/features.py`：从 `build_skill_system_prompt` 抽离 `resolve_skill(skill_id, task)` 公共函数，供技能装配与步骤信息复用，行为不变；
- `/api/chat` 流式通道在 token 输出前依次推送 6 类步骤事件（`{"step": {...}}`）：
  1. **解析创作任务** — 任务类型 · 篇幅 · 选区字数 · 挂载上下文项数；
  2. **匹配写作技能** — 命中技能标题（name@version · 内置/自定义/迁移/导入）；
  3. **装载方法论参考** — 该技能挂载的 references/ 文档清单与份数（无挂载则省略此步）；
  4. **装配系统提示词** — 装配后规模（字数）；
  5. **连接模型** — 当前配置的模型名；
  6. **生成正文** — 流式输出中（doing）→ 输出 N 字 · 用时 X.Xs（done）/ 失败原因（error）。
- 步骤终态随 AI 回复一并持久化到 `chat_messages.meta_json.steps`，历史消息可折叠回放；非流式模式同步携带。

### 2.2 前端：聊天气泡思考过程组件（`static/js/pages/workbench_chat.js`）

- 新增 `buildStepsBox()` 组件：步骤行（状态图标：进行中旋转 / 完成对勾 / 失败红色）+ 标题 + 明细；
- 生成中：思考面板自动展开，步骤逐条实时出现，摘要行滚动显示当前进行步骤；
- 完成后：自动折叠为「已完成思考 · N 步」单行摘要，点击可展开回看；
- 中断/失败：摘要变为「思考过程 · 生成中断（N 步）」，失败步骤红色标记；
- 历史消息：读取 `meta_json.steps` 渲染折叠态思考摘要，刷新页面后仍可查看；
- 无任何步骤时不渲染面板（防空气泡）；
- 实机验证修复：步骤状态切换时图标 className 重写丢失了 `material-symbols-outlined` 基类（图标退化为原始文本并挤压布局），已补回；步骤标题/明细改为纵向两行排布，明细占满剩余宽度，摘要行防换行。

### 2.3 测试与文档

## 4. 改动边界与已知问题

- 仅覆盖聊天通道（修撰使对话框）；经典多候选面板走 `/api/ai/generate` 多候选通道，保留原有状态栏文案，未接入步骤追踪；
- 步骤信息为本地装配过程的真实记录，不包含模型侧思维链（绝大多数创作模型不输出 reasoning 内容）；
- 已知历史问题（自 v1.7.3 起存在，未在本版处理）：GitHub Release 上传的 exe 为英文名 `MoYu-vX.Y.Z-win64.exe`，而 `dist/manifest.json` 记录的是中文名。
