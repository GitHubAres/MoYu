# 墨语 MoYu v1.7.9 开发说明

- **版本号**：1.7.9
- **更新日期**：2026-10-04
- **基线**：v1.7.8（技能选择迁移至聊天输入区任务标签旁）

## 一、本版需求来源

用户实机测试 v1.7.8 后反馈 6 项问题/改进：

1. 写作工作台「修撰使精调选项—长度」的「简/中/长」语义模糊，希望改为具体字数档位并支持自定义字数；
2. Skill 市场点「删除」按钮报错 `api.delete is not a function`；
3. 内置 Skill「编辑参考文档内容」弹窗打开后 textarea 空白，不显示现有内容；
4. 系统设置—AI 模型配置—模型名下拉菜单点击选项不会填入输入框；
5. 「数据与备份」希望支持自定义数据保存路径；
6. 「快速记录」悬浮按钮（FAB）固定位置遮挡内容，希望可按住拖动摆放。

## 二、改动明细

### 1. 生成长度字数化（1000/2000/3000 字 + 自定义）

- **前端** `static/js/pages/workbench.js`：
  - `aiLength` 默认值由 `"medium"` 改为 `"2000"`，并从 `localStorage["moyu_ai_length"]` 恢复用户偏好；
  - 长度分段按钮改为 `1000字 / 2000字 / 3000字` 三档，旁置「自定义字数」数字输入框（100~20000），输入即生效并持久化；自定义值生效时三档按钮自动取消高亮（`seg.sync()` 的严格相等判断天然支持）；
  - 任务请求载荷 `length` 直接携带数字字符串（如 `"2000"`）。
- **前端** `static/js/pages/workbench_chat.js`：`window.aiLengthPreference` 兜底值同步为 `"2000"`。
- **后端** `app/features.py`：新增 `AIOrchestrator.length_hint()` 静态方法——数字字符串生成「控制在 N 字左右」提示语，非数字回退旧 `LENGTH_HINTS`（short/medium/long），兼容大纲生成等仍发旧键的调用方；`build_skill_system_prompt` 与兜底提示词拼接处统一改调该方法。
- **后端** `app/api/chat.py`：思考步骤「解析创作任务」的长度标签支持数字档位显示（如「2000字」）。

### 2. Skill 市场删除报错修复

- **根因**：`static/js/api.js` 只注册了 `del` 方法，而 Skill 市场前端调用 `api.delete`。
- **修复**：`api.js` 补齐 `delete`（DELETE）与 `put`（PUT）两个方法，`del` 保留兼容。

### 3. 参考文档编辑弹窗空白修复

- **根因**：`static/js/ui.js` 的 `ui.el()` 对 `value` 键走 `setAttribute`，而 `<textarea>` 的初始内容不由 value 属性控制，导致赋值无效。
- **修复**：`ui.el()` 增加 `k === "value"` 分支，直接赋值 DOM 属性 `node.value = v`。

### 4. 模型名下拉点击不填充修复

- **根因**：`static/js/pages/settings.js` 模型下拉项的 `onmouseenter` 处理器会调用 `renderItems()` 重建整个列表 DOM；鼠标按下（mousedown）与抬起（mouseup）落在不同的 DOM 元素上，浏览器不派发 click 事件。
- **修复**：`onmouseenter` 不再重建 DOM，仅更新 `activeIndex` 并遍历现有子节点切换高亮 className。

### 5. 数据目录自定义路径

- **后端** `app/paths.py`：数据目录解析优先级调整为 `MOYU_DATA_DIR 环境变量 > EXE 旁 moyu_config.json 的 data_dir 字段 > 默认 EXE 旁 data/`；新增 `CONFIG_PATH` 常量。
- **后端** `app/api/prefs.py`（同时把混合行尾统一为 CRLF）：新增三个路由——
  - `GET /api/settings/data-dir`：返回 current/default/custom/env_override/db_path；
  - `POST /api/settings/data-dir` `{path, migrate}`：校验绝对路径并建目录；`migrate=true` 时复制 `moyu.db`、`exports/`、`imports/`（目标已存在则跳过并记录）；写入 `moyu_config.json`，返回 `need_restart`；
  - `DELETE /api/settings/data-dir`：移除自定义配置恢复默认。
  - 环境变量 `MOYU_DATA_DIR` 已设置时 POST 返回 400 并说明原因。
- **前端** `static/js/pages/settings.js`：「数据与备份」区块新增「自定义数据目录」面板——当前生效目录展示、路径输入框、「迁移现有数据」勾选（默认勾选）、保存/恢复默认按钮与「重启后生效」提示。
- `.gitignore` 增加 `moyu_config.json`。

### 6. 快速记录悬浮按钮可拖动

- **前端** `static/js/app.js`：FAB 改为 pointer 事件驱动拖动——5px 阈值区分点击与拖动、`setPointerCapture` 跟手、视口边界钳制（4px 边距）、位置持久化到 `localStorage["moyu_quicknote_fab_pos"]`、拖动后吞掉紧随的 click 避免误开弹窗、窗口 resize 时重新钳制；显式 `left/top` 用 `setProperty(..., "important")` 覆盖 app.css 中的 `bottom: ... !important` 安全区规则。

### 7. 版本同步

- `app/version.py`：1.7.8 → 1.7.9；`tests/test_deploy_and_env.py` 断言同步；
- `static/index.html` 缓存戳：`api.js`/`ui.js`/`app.js`（1.2.6→1.7.9）、`settings.js`（1.7.5→1.7.9）、`workbench.js`/`workbench_chat.js`（1.7.8→1.7.9）；
- `AGENTS.md`、`README.md`、`docs/PRD-本地版.md` 版本号同步；README 更新表新增 v1.7.9 行。

## 三、测试回归

- 自动化：**113 项全绿**（v1.7.8 的 105 项 + 新增 8 项）。
- 新增用例：
  - `tests/test_skills.py`：`test_length_hint_numeric_and_legacy`（数字档位 + 旧键兼容 + 回退）、`test_numeric_length_in_prompt`（字数进入系统提示词）；
  - `tests/test_data_dir.py`（6 项）：GET 默认态、POST 校验（空路径/相对路径 400）、迁移复制与配置写入、已存在跳过、DELETE 恢复默认、环境变量覆盖时 POST 拒绝。
- 实机验证：隔离数据目录 + SSE mock 模型源跑通写作工作台长度档位/自定义字数生成链路、Skill 删除与参考文档编辑、设置页数据目录面板与 FAB 拖动。

## 四、改动边界与已知问题

- 数据目录自定义**重启后生效**（`DATA_DIR`/`DB_PATH` 在进程启动时一次性解析），前端已明确提示；迁移为「复制」而非「移动」，旧目录数据保留，需用户自行清理。
- 环境变量 `MOYU_DATA_DIR` 优先级最高，设置页在检测到该变量时禁用并说明（Docker/VPS 部署场景）。
- 长度自定义上限 20000 字仅为前端输入约束，实际生成篇幅仍受所选模型上下文与输出上限约束。
- 大纲生成（outline.js）仍发送旧 short/long 键，后端 `length_hint` 保持兼容，不在本版改造范围。
