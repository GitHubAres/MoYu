- **发布日期**：2026-10-05

---

## 1. 本次更新核心功能

### 1.1 写作工作流：智能多备选方案识别与一键采纳
- **背景**：写作技能在进行大纲设计、情节推演、角色设定等构思时，AI 往往会输出【方案一】、【方案二】、【方案三】等多个备选方案。此前用户必须先点“编辑后继续”，在文本框中费力手动删减无用方案才能推进。
- **改动**：
  - 在步骤运行结果渲染（`static/js/pages/workflows.js`）中引入智能方案解析器 `parseWorkflowOptions`，支持常见中英文模式识别（`【方案X】`、`### 方案 X`、`方案 X:`、`Option X` 等）；
  - 检测到 ≥2 个备选方案时，自动展开备选方案卡片网格；
  - 每个方案卡片提供独立的 **「选用此方案继续」** 按钮，点击后自动提取该方案内容并推进到工作流下一步，同时自动记录操作备注；
  - 完美保留全量采纳与自由编辑能力。

### 1.2 AI 客户端与网关诊断能力强化
- **连接测试 token 宽松化**：将 `app/features.py:test_connection` 的测试上限从 `max_tokens=1` 放宽至 `max_tokens=64`，彻底解决如 `gemini-3.8-flash`、深度思考/Reasoning 模型及网关（如 sub2api）在 1 个 token 预算下返回空内容（Empty 200）的缺陷。
- **错误诊断友好化**：`app/ai_client.py:chat` 对非 JSON 及空响应进行细粒度防御捕获，若接口返回空内容或反向代理 HTML 网页，提供包含 HTTP 状态码与截取详情的友好提示，杜绝抛出原始晦涩的 `JSONDecodeError: Expecting value: line 1 column 1 (char 0)`。
