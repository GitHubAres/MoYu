- 日期：2026-09-26

## 1. 相对原 PRD 的裁剪

### 1.1 移除（本地版不实现）

| 原功能 | 移除原因 |
|---|---|

## 2. 产品定义

「墨语MoYu」本地版面向网文作者与长篇创作者，提供从灵感整理、作品规划、正文创作、设定管理到作品导出的连续创作体验。**全部数据存储于本地 SQLite**，AI 是可控的创作助手：所有 AI 内容先预览、再由用户确认，不静默写入正文。

产品气质：安静、沉浸、有文气（沿用 Literary Minimalist Ink 设计系统：黛青 `#1B2A38` 主色、朱砂 `#D9483B` 强调、Noto Serif 标题 + Plus Jakarta Sans 正文）。

## 3. 核心任务流程（本地化后）

### 3.1 首次使用

启动 exe → 自动打开浏览器进入书架 → （可选）在设置页配置 AI API → 创建作品或导入 TXT/DOCX → 新建卷/章 → 开始写作。提供"创建示例作品"演示数据入口。引导可跳过。

### 3.2 日常续写

书架"继续写作" → 打开最近章节 → 写作（自动保存，状态可见）→ 选区或全文发起 AI 操作 → 差异预览 → 采纳/放弃 → 采纳可撤销，进入版本历史。

### 3.3 大纲到正文

编辑大纲节点 → "生成章节草稿" → 确认上下文 → 预览候选 → 采纳到草稿（不覆盖已有正文，已有正文须选插入位置并可恢复）。

### 3.4 设定检查（简版）

选择章节范围 → 发起 AI 检查 → 查看问题列表及原文引用 → 跳转定位 / 忽略。检查结果仅为建议，不修改内容。

## 5. 功能需求（本地版）

### 5.1 书架

- 作品卡片：封面占位、书名、总字数、最近编辑时间、最近章节；"继续写作"直达。
- 新建 / 重命名 / 删除（删除二次确认，说明影响）/ 导入作品；按书名搜索、按最近编辑排序。
- 全站累计字数、当日字数、连续写作天数统计。
- 灵感便签侧栏：创建、编辑、删除、关联作品（简版）。

### 5.2 创作工作台

- 三栏布局：目录（作品→卷→章，增删改、排序、状态：草稿/已完成）｜编辑器｜AI 侧栏；侧栏可收起，布局偏好本地保存。
- 编辑器：纯文本段落模式（首发唯一编辑模式）、撤销/重做、查找替换、章节字数与作品累计字数、日目标进度。
- 自动保存：输入停止约 2 秒触发；状态显示"正在保存 / 已保存 / 保存失败"，失败保留本地内容并提供重试。
- 专注模式：隐藏侧栏，仅留正文；退出恢复。
- 选区工具：续写、扩写、缩写、改写润色；结果以差异预览呈现。

### 5.3 AI 助手

- 设置页配置 OpenAI 兼容接口（Base URL、API Key、模型名），提供"测试连接"。
- 任务可选：续写 / 扩写 / 缩写 / 改写润色 / 大纲生成 / 设定检查；长度（简/中/长）与候选数量可选。
- 发起前展示本次上下文来源（当前章节、前情摘要、关联设定），可逐项取消。
- 流式生成，可停止；停止后已生成内容保留在候选区。
- 候选支持整体采纳、复制、重试；采纳写入可撤销并自动进入版本历史；替换已有正文需二次确认。
- 未配置 API 时，AI 入口给出明确引导（跳转设置），不报错死路。

### 5.4 大纲

- 树形节点（作品/卷/章层级），节点含标题、梗概、状态；支持排序与关联章节。
- AI 生成/扩写大纲先进入预览态，采纳后写入。

### 5.5 设定库

- 分类：角色 / 地点 / 势力 / 物品 / 术语 / 自定义；条目含名称、正文、标签、更新时间。
- 新增、编辑、搜索、归档/删除；可关联章节，详情显示关联章节。
- 角色模板字段：姓名、身份、性格、背景、目标与变化（空字段不强制）。

### 5.6 版本历史

- 按章节列出自动快照与手动快照（时间、来源：自动/手动/AI 采纳/恢复、标签）。
- 双栏差异对比（行级）；恢复前自动留存当前版本；恢复操作可撤销。
- 保留策略：自动快照每章保留最近 30 份，手动快照不限（本地策略，可在设置调整）。

### 5.7 导入导出

- 导入：TXT / DOCX；上传后按章节标题规则预览拆分，确认后入库；失败保留原文件并说明原因。
- 导出：范围（全书 / 卷 / 勾选章节）；格式 TXT / DOCX；排版选项（首行缩进、章节标题格式化、附录设定）；导出历史列表与下载，失败可重试。

### 5.8 设置

- 主题：浅色（默认）/ 深色 / 纸张色。
- 编辑器：字号、行距、自动保存间隔。
- AI：Base URL、API Key、模型名、测试连接；用量估算展示（标明口径）。
- 数据：数据目录位置说明、手动备份（导出整库）。

### 5.9 伏笔看板（P1 简版）

按"已埋设 / 待回收 / 已回收"分栏列表；新建、编辑、改状态、关联章节。

### 5.10 提示词中心（P1 简版）

内置预设（续写/扩写/改写/润色/大纲/检查）+ 自定义模板 CRUD；工作台 AI 侧栏可调用模板。

## 6. 交互与状态规则（沿用原 PRD 第 6 节，去除云端项）

- AI 内容与正文视觉区分，默认暂存/预览态；采纳、替换、批量写入均可撤销并进版本记录。
- 保存失败保留本地输入并持续提示，提供重试。
- 超过 300ms 的操作提供可见反馈；AI/导出等长任务可取消。
- 全局搜索（作品/章节/设定）；快捷键遵循系统惯例，设置页可查。

## 7. 验收标准（本地版）

1. 双击 exe 启动后自动打开浏览器进入书架；数据落盘于 exe 旁 `data/`。
2. 可创建/导入作品，建卷/章并编辑；重开应用回到最近章节。
3. 自动保存状态可见；模拟保存失败时内容不丢，可重试。
4. 配置 API 后可流式续写/改写；未确认前不改正文；停止后候选保留。
5. 采纳 AI 内容可撤销；可从版本历史找回采纳前内容；替换正文有二次确认。
6. 设定条目可建/改/搜，可关联章节；AI 检查结果附原文引用或标注无依据。
7. 版本差异可查看、可恢复；恢复前正文自动留存。
8. TXT/DOCX 导出范围与目录结构符合选择；导入拆章预览正确。
9. 关键状态在浅色/深色/纸张主题下均可辨识，不只靠颜色表达。
10. 全程离线可用（除 AI 调用本身）：字体、样式、图标均为本地资源。
