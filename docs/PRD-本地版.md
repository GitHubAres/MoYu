# 「墨语MoYu」本地与私有云写作工作台｜产品需求文档（v2.1.1）

- 版本：v2.1.1（以代码实际功能为准）
- 日期：2026-10-07
- 依据：依据当前代码库（`app/` 与 `static/js/pages/`）实际已实现功能全面盘点重写
- 范围：**本地单机部署、单用户**、Windows 轻量原生应用窗口（WebView2 驱动，无黑框控制台，点叉即退；亦支持 --browser 外部浏览器访问），最终交付物为 PyInstaller 单 exe（墨语MoYu-v2.1.1-win64.exe）
- 技术形态：Python FastAPI + SQLite + 原生 JavaScript SPA 单页应用，AI 走用户自配置的 OpenAI 兼容 API

---

## 1. 版本与功能范围综述

墨语 v1.2.3 已经完成从早期单一章节写作向长篇小说全生命周期工作台的演进。数据全部存储于本地 SQLite，采用本地优先架构。

### 1.1 核心设计与交互原则
1. **内容安全红线**：AI 生成内容必须先提供差异对比预览或多候选预览，经用户显式采纳确认后方可写入作品；任何路径严禁静默改写或覆盖正文。
2. **可撤销与版本溯源**：所有 AI 采纳、大段修改均自动沉淀版本快照，支持无损回退。
3. **零云端依赖与资产私有**：作品、大纲、人物、伏笔、设定均存放在本机 `data/` 目录；无需云端登录、无商业收费。
4. **统一设计语言**：遵循 Literary Minimalist Ink 规范，以黛青（`#1B2A38`）为主色、朱砂（`#D9483B`）为强调色，搭配 Noto Serif 衬线标题与 Plus Jakarta Sans 正文字体，支持浅色/深色/纸张色三种主题。

## 2. 核心创作任务流

### 2.1 灵感孵化到一键开炉（炼丹炉）
1. 执笔人在**炼丹炉**输入核心脑洞或一句话构思；
2. AI 推演并生成推荐书名、题材受众、核心卖点与主线脉络；
3. 进一步推演世界观架构与主要出场角色；
4. 点击“开炉建书”，系统自动在书架创建新作品，并将推演得到的大纲结构写入大纲库、角色与规则写入设定库。

### 2.2 日常写作与 AI 辅助（工作台）
1. 从书架点击“继续写作”，自动打开上次编辑的章节；
2. 写作过程中，本地定时自动保存并实时计算字符字数（`word_count` 过滤无意义空白）；
3. **选区触发**：选中正文特定段落，悬浮工具栏唤起扩写、缩写、改写或自定义指令；
4. **光标触发**：光标停在文末，AI 结合挂载的上下文（前文内容、大纲摘要、勾选的人物设定）流式生成 1~3 个候选方案；
5. **对比采纳**：用户查看行级 LCS 差异对比，满意后点击“采纳”，正文替换并在版本库中自动备份采纳前快照。

### 2.3 设定与伏笔编织（大纲 / 看板 / 图谱 / 时间线）
1. 创作长篇时，在大纲页规划各卷主线与章节细纲；
2. 在设定库与关系图谱中维护人物关系链条，确保复杂人际网络清晰可见；
3. 在伏笔看板中记录关键埋点，在正文提及或回收时拖动状态，防止长篇遗忘弃坑；
4. 在时间线中校准重大历史节点，保持叙事时间轴稳定。

### 2.4 全书质检与归档（一致性检查 / 导入导出）
1. 完稿或阶段性章节完成后，发起一致性检查，由 AI 对比设定库（如外貌特征、力量体系等），指出潜在前后矛盾点；
2. 在导入导出模块中一键导出标准 `.docx` 或 `.txt` 排版文稿，或备份全书结构包。

## 3. 功能详细说明

### 3.1 书架与仪表盘（`bookshelf.js`）
- **Dashboard 统计**：累积总字数、今日字数（对比每日目标）、作品总数、章节总数。
- **作品卡片**：封面底色渐变/用户自定义封面图片、字数统计、更新时间、连载状态。
- **快捷操作**：“继续写作”直达最近章节、编辑作品属性、重命名作品、安全确认删除作品、创建示例作品（《太虚仙途》）。

### 3.2 写作工作台（`workbench.js`）
- **左栏目录树**：卷章层级展开/折叠、拖拽调序、卷章新建/重命名/删除、字数动态汇总。
- **中栏编辑器**：大字号衬线沉浸纯文本编辑、无样式粘贴过滤、查找替换框、专注全屏模式、打字机视感。
- **右栏 AI 修撰使（v1.3.0 多轮对话聊天窗口升级）**：
  - **多轮对话伴写**：按章节独立维护对话会话与历史（`chat_sessions` / `chat_messages`），支持 ≥3 轮连贯上下文推演，支持一键「新对话」重置轮次；
  - **任务模式与快捷标签**：续写（continue）、扩写（expand）、缩写（condense）、改写润色（polish），输入框上方可快捷点击切换并自动聚焦；
  - **上下文与选区深度感知**：自适应挂载当前章节前文、上一章末尾 500 字前情摘要、当前大纲节点细纲，以及设定库动态识别实体；选中文本后自动激活输入框“已引用选区”提示条；
  - **流式打字与纯文本渲染**：SSE 原生流式逐字打字机效果呈现，打字过程中支持一键中断；
  - **安全采纳与原子撤销**：AI 生成内容未点「采纳」绝不写入正文；点击采纳前系统自动留存版本快照，采纳后气泡原地提供「撤销采纳」可一键复原；
  - **经典候选模式开关**：设置抽屉内内置“经典多候选对比模式”开关，开启后即可无缝切回并排多候选生成与 LCS 行级 Diff 对比面板。

### 3.3 故事大纲与推演（`outline.js`）
- 树状卷章大纲视图，支持节点增删改、大纲摘要提炼。
- AI 剧构推演：根据选中节点一键推演后续情节点、生成章节正文草稿并支持一键送入工作台编辑。

### 3.4 设定库与知识体系（`entities.js`）
- 分类标签支持：人物、世界观、功法/物品、组织势力、自定标签。
- 实体属性：名称、别名、身份阵营、外貌特征、性格特点、能力设定、背景经历。
- 工作台联动：正文提及实体时支持智能关联与上下文挂载。

### 3.5 伏笔看板（`board.js`）
- 三分栏泳道：未解伏笔（未回收）、推进中（已发酵）、已收线（已圆满）。
- 伏笔记录：伏笔名、关联章节、埋笔描述、回收设想，支持流转状态与快速定位。

### 3.6 关系图谱（`graph.js`）
- 采用力导向交互式网络可视化，展示人物实体之间的关联。
- 支持动态新增/编辑连线关系（如盟友、宿敌、师徒、情仇），直观展现势力纠葛。

### 3.7 剧情时间线（`timeline.js`）
- 纵向时间轴渲染重大事件序列。
- 记录纪元时间、事件概要、关联人物、涉及章节，帮助梳理长篇时间跳跃。

### 3.8 炼丹炉（`alchemy.js`）
- 结构化创意向导：骨架推演（书名/类型/卖点/主线）→ 世界观推演（法则/力量等级/势力分布）→ 角色孵化（主角/宿敌/配角关系）。
- 支持一键将推演成果实体化为书架作品。

### 3.9 丹青阁（`gallery.js`）
- 本地艺术画廊，与外接绘图能力对接，支持生成作品封面与人物立绘，并支持与作品一键绑定。

### 3.10 版本快照与对比（`versions.js`）
- 章节修改自动按变更阈值与 AI 采纳时机打桩留存快照。
- 支持任意两个历史快照版本之间的行级 LCS 差异对比，支持安全回退。

### 3.11 一致性检查（`audit.js`）
- 章节正文与设定库实体的矛盾检测（如发色突变、前后战力体系错乱、死而复生等）。
- 输出具体冲突原因、涉及实体、原文证据段落及修改指引。

### 3.12 导入导出（`io.js`）
- 导入：支持选择本地 `.txt`、`.docx` 文档，自动根据正文正则识别分卷分章并导入墨语作品树。
- 导出：导出整本小说或独立章节为格式规整的 `.txt` 或排版优美的 `.docx` 文件。

### 3.13 Skill 市场（`skills.js`）
- 预置官方精调的续写、扩写、缩写、改写、大纲生成、设定检查六类 Agent Skill，内置技能随版本自动升级。
- 技能 = 元数据 + 核心指令 + 按需挂载的 references/scripts 资源文件，生成时渐进式装配进系统提示词。
- 支持导入 `.skill` 包、新建/编辑/复制/启用禁用自定义技能、规范校验与导出分享；写作工作台按任务自动匹配技能，亦可在聊天输入区任务标签旁的技能菜单中为每个任务单独绑定技能（本地记忆）。

### 3.14 异步任务中心（`tasks.js`）
- 记录长文本推演、全文一致性审查等耗时操作。
- 显示任务耗时、token 消耗概算、状态及重试按钮。

### 3.15 系统设置（`settings.js`）
- AI 连接测试（Base URL + API Key + Model）。
- 任务模型分流路由：续写改写模型与深思考推理模型支持独立配置。
- 外观与界面：浅色、深色、纸张色三套精修配色切换，字号与行距微调，每日字数目标维护。
- **软件自动更新模块**：
  - 支持 stable (稳定版) 与 beta (尝鲜测试版) 双通道；
  - 内置 semver 版本解析与 10 分钟防抖缓存，支持配置国内 GitHub 镜像加速；
  - 桌面端：新版本特性日志弹窗/卡片预览、SHA256 校验码展示、安装包一键下载引导、支持跳过当前版本；
  - VPS 生产端：环境自动识别（桌面/Docker/systemd/源码），systemd 模式支持应用内一键安全升级（先自动在 `data/backups/` 创建 SQLite 快照，后拉取源码与依赖并平滑重启），Docker 容器模式提供 Watchtower 持续集成指南。

## 4. 关键技术约束与非功能要求

1. **零外部数据库**：严格基于标准 `sqlite3` 本地文件驱动，所有新字段通过 `db.py` 增量迁移脚本管理。
2. **纯前端无编译**：前端全部使用现代原生 JavaScript（ES Modules / 原生 DOM 操作），Tailwind CSS 在浏览器端运行时解析，杜绝 npm 构建打包门槛。
3. **打包一体化**：Windows 最终发布形态统一为 `墨语MoYu-v1.8.1-win64.exe` 单文件绿色版，开箱即用，自动生成 exe 同级 `data/` 目录保存用户数据。
4. **单实例守护**：内置 8321 端口单实例检测，若已存在运行实例则直接调起浏览器打开页面，避免多开冲突。
