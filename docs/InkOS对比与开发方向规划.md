# InkOS 对比与墨语开发方向规划

> 更新：2026-09-28。本文用于梳理长篇小说创作能力方向，具体排期以产品任务安排为准。

## 1. 产品立场

墨语服务长篇小说作者，保持本地优先与 AI 辅助创作体验。AI 负责提出候选、整理信息和提供检查意见；正文由作者预览确认后再采纳，不做静默连写或自动改稿。

## 2. 能力方向

### 长篇编排

- 支持多候选生成。
- 组装前情摘要和用户选定的相关设定，作为生成上下文。
- 所有生成结果沿用预览、确认、版本记录和撤销流程。

### 设定状态

- 以作品设定库为基础，探索维护伏笔状态与角色持有物。
- 章节采纳后可提示作者检查并更新相关状态；状态变更须由作者确认。

### 连续性检查

- 面向网文创作检查角色知识边界、物品连续性、伏笔回收、称谓和时间线。
- 检查结果列出原文依据，供作者逐条查看、处理或忽略，不自动改正文。

### 文风辅助

- 探索从作者正文提取句长、节奏和用词偏好，作为可编辑的文风参考。
- 提供词汇疲劳和套话提示，改写结果须经过作者预览确认。

## 3. 暂不追求的方向

- 不做未经作者确认的自动连写、静默写作或自动改正文。
- 暂不扩展为互动影游、多语言翻译或 CLI/Agent 优先产品。
- 移动端与多设备能力后续评估。

## 4. 规划参考表

| 方向 | 目标 | 处理原则 |
|---|---|---|
| AI 编排 | 多候选、摘要和设定注入 | 作者可检查生成上下文与结果 |
| 设定状态 | 伏笔和角色持有物的变化记录 | 变更需人工确认 |
| 连续性检查 | 发现长篇内容中的矛盾线索 | 只提供证据和建议 |
| 文风辅助 | 提取偏好并给出体检建议 | 不做对抗检测，改写经用户确认 |
| 自动写作 | 后台持续生成正文 | 不纳入产品方向 |
