**版本号：** v1.9.0  
**更新日期：** 2026-10-07  
**定位：** 功能去重与体验一体化重构（一体化写作台 · 剧情脉络三位一体 · 设定图谱反哺联动）

## 一、本次迭代概述与核心痛点解决

在经历多个版本的敏捷演进后，墨语功能体系日益完善，但也积累了部分交互碎片化与冗余入口问题。依据《墨语 MoYu 功能去重与体验一体化重构开发计划书 (v1.9.0)》（`docs/v1.9.0-reconstruction-plan.md`），本次 v1.9.0 进行了彻底的去重与体验一体化收敛：

1. **工作台 AI 伴写能力一体化：**
   - 彻底打破原来“经典多候选模式”与“修撰使对话抽屉”割裂的二元状态；
   - 移除抽屉与重复的展开配置，将任务类型（续写、扩写、缩写、润色、推演）、字数档位（500/1000/2000/3000）与候选数量（1/2/3）无缝整合在伴写输入区；
   - 支持多候选生成卡片在单栏流式输出与多栏并排对比之间自适应切换，提供清晰的采纳/撤回状态流。

2. **功能入口去重与降噪：**
   - 清理与写作工作流功能重叠的“开炉炼丹”冗余页面逻辑，平滑引导至写作工作流体系，降低认知负担。

3. **剧情脉络三位一体（大纲 - 时间线 - 伏笔）：**
   - 数据库 Migration 16 落地，为 `timeline_events` 与 `foreshadows` 建立 `outline_node_id` 外键关联与索引（支持节点级联置空）；
   - 后端新增大纲节点剧情聚合端点 `GET /api/works/{work_id}/outline/nodes/{node_id}/plot-items`，大纲树端点聚合返回各节点的关联时间线与伏笔计数；
   - 前端大纲树节点直观展示关联数量徽章；大纲节点详情面板新增【剧情脉络】专区，并支持一键快捷添加时间线事件与埋设伏笔；
   - 时间线与伏笔看板卡片上展示关联大纲节点徽章，点击即可平滑跳转定位大纲节点；新建与编辑弹窗支持大纲节点下拉选择。

4. **设定档案关系维护与图谱反哺：**
   - 设定编辑面板新增【人物与势力关系网络】交互模块，支持直观添加/移除与其他实体的羁绊关系与称谓标签（如师徒、同盟、宿敌等）；
   - 级联保存 `relations` 并在图谱端点自动反哺，无需手动切页绘制拓扑关系。

## 二、后端新增与增强端点

| 方法 | 路径 | 功能说明 |
|------|------|----------|
| `GET` | `/api/works/{work_id}/outline/nodes/{node_id}/plot-items` | 聚合获取指定大纲节点关联的全部时间线事件与伏笔列表 |
| `GET` | `/api/works/{work_id}/outline` | 增强：树节点包含 `timeline_count` 与 `foreshadow_count` 聚合计数 |
| `POST/PATCH` | `/api/works/{work_id}/timeline/events` / `/api/timeline/events/{id}` | 增强：支持 `outline_node_id` 绑定与修改，返回包含大纲节点标题 |
| `POST/PATCH` | `/api/works/{work_id}/foreshadows` / `/api/foreshadows/{id}` | 增强：支持 `outline_node_id` 绑定与修改，返回包含大纲节点标题 |
| `POST/PATCH` | `/api/works/{work_id}/entities` / `/api/entities/{id}` | 增强：支持 `relations: [{to_id, label}]` 级联保存与关系图谱反哺 |
| `POST` | `/api/chat` | 增强：支持 `candidates` 多候选生成参数及流式 candidate 帧分发 |

## 三、前端文件与架构改进

- `static/js/pages/workbench.js`：移除割裂的经典抽屉与切换开关，深度集成 `WorkbenchChat` 伴写引擎；
- `static/js/pages/workbench_chat.js`：内置 5 大任务药丸切换、字数档位与候选数量快捷栏，多候选卡片并排与 Tab 流式切换；
- `static/js/pages/alchemy.js`：清退冗余界面，平滑重定向引导；
- `static/js/pages/outline.js`：大纲树徽章展示、URL `?node_id=` 智能选区高亮、剧情脉络专区与快捷添加弹窗；
- `static/js/pages/timeline.js`：关联大纲节点下拉选择与点击跳转大纲徽章；
- `static/js/pages/board.js`：伏笔卡片大纲徽章穿透跳转与新建/编辑大纲节点下拉选择；
- `static/js/pages/entities.js`：设定详情维护人物/势力关系网络并自动保存同步图谱。

## 五、改动边界与已知事项

1. 数据库兼容：本次 Migration 16 采用标准 `ALTER TABLE ... ADD COLUMN` 语法，平滑兼容所有旧版本已有 SQLite 数据库，无破坏性变更；
2. 离线能力：所有改动严格遵守原生 JavaScript 与 DOM API 规范，无 Node 构建包依赖，离线环境下 WebView2 体验完整稳定。
3. **缺陷快速修复 (Hotfix)：**
   - 修复了 `workbench_chat.js` 在输入栏装载时因缺失 `selQuoteBox`（选区引用提示条）声明引发的 `Can't find variable: selQuoteBox` 页面崩溃报错；
   - 补齐了 `selQuoteBox` DOM 节点构建、选区字数动态更新方法 `updateSelectionQuote()`，并在初始化阶段自动激活 `continue` 任务；
   - 在 `tests/test_chat.py` 中固化自动化静态断言，杜绝选区提示条相关变量遗失。
