## 1. 本版本核心变更与完成事项

1. **架构与许可路线重构**：
   - 彻底放弃防抄袭/AGPL 路线，全库回归纯 MIT 开源。
   - 移除 `licensing/`、`core_api/`、`.pyarmor/` 目录以及 `app/api/update.py`。
   - 移除了启动时的许可证网络强校验，确保无私有包状态下本地全部写作与 AI 辅助能力开箱即用。
   - 物理删除外部私钥目录 `D:\KimiCode工作区\moyu-core\`。

2. **关键 Bug 修复**：
   - **写作工作台 TDZ 错误修复**：解决了书架页面点击“继续写作”跳转至写作工作台时触发的 `Cannot access 'relatedBox' before initialization` ReferenceError，确保 DOM 布局完成后再进行变量绑定。
   - **快照渲染防御**：修复了版本快照链接在 `chapter` 为 `null` 时抛出异常的问题。
   - **快捷链接符号修复**：修复了右侧栏快捷链接的双引号字符串字面量转义问题。

3. **构建流程与规范统一**：
   - `build_exe.py` 改造为在独立临时目录拷贝 `static/` 并自动注入 `?v=<VERSION>` 缓存戳，绝不回写源码工作区。
   - 打包产物统一规范命名为 `墨语MoYu-v1.1.0-win64.exe`，打包后自动生成 SHA256 校验清单。

4. **自动化测试覆盖体系扩充**：
   - 新增 `tests/test_v11_features.py`，补齐了 v1.1 新增模块的自动化测试。
   - 当前全量测试套件达到 **39 项，通过率 100%**：
     - 作品/分卷/章节 CRUD (`test_works.py`)
     - 实体/大纲/伏笔/便签/提示词 (`test_entities_notes_prompts.py`, `test_seed_outline.py`)
     - 版本快照与版本回滚 (`test_versions.py`)
     - 导入与导出 (`test_io.py`)
     - 关系图谱 / 剧情时间线 / 文风档案 / AI 任务队列 / 丹青阁封面 (`test_v11_features.py`)

## 2. 真实功能模块与路由概览

当前项目共注册 19 个 API 模块，前端通过纯原生 JS 路由驱动：
- **书架与基础**：`/api/works`、`/api/volumes`、`/api/chapters`、`/api/prefs`
- **核心写作与版本**：`/api/versions`、`/api/search`、`/api/io` (导入导出 txt/docx/json)
- **设定与伏笔**：`/api/entities`、`/api/board` (伏笔看板)、`/api/notes` (便签)
- **大纲与种子**：`/api/outlines`、`/api/seed`
- **AI 助手与提示词**：`/api/ai`、`/api/prompts`、`/api/audit`
- **v1.1 扩展功能**：
  - 关系图谱：`/api/works/{id}/graph`、`/api/works/{id}/relations`
  - 剧情时间线：`/api/works/{id}/timeline`、`/api/timeline/import`
  - 文风档案：`/api/works/{id}/style`
  - 炼丹炉：`/api/alchemy`
  - 丹青阁：`/api/gallery`、`/api/works/{id}/cover-upload`
  - 异步任务：`/api/tasks`

## 3. 设计语言与交互红线

- **设计风格**：Literary Minimalist Ink
- **色彩规范**：主色 黛青 `#1B2A38`，强调色 朱砂 `#D9483B`
- **字体体系**：标题 Noto Serif，正文 Plus Jakarta Sans
- **核心交互红线**：
  - AI 生成内容必须先进行预览对比、经用户显式确认采纳后才可写入正文或版本。
  - 任何代码路径均严禁静默覆盖改写正文。

## 4. 下一版本待办清单（Roadmap）

1. **写作工作台实体上下文联动**（✅ 2026-09-30 已完成）：
   - 位置：`static/js/pages/workbench.js` & `app/api/entities.py`
   - 实现：全书设定库动态联动、大纲细纲自动注入、正文实体实时智能识别（提及标注与一键固定绑定）、结构化实体上下文装配（类别/标签/关键属性/详述）、工作台快速关联与设定详情预览弹窗。
2. **炼丹炉底层生成能力深化**（✅ 2026-09-30 已完成）：
   - 位置：`app/features.py`（`AlchemyEngine` & `StyleEngine`）
   - 实现：
     1. 拆书蒸馏（`/alchemy/analyze` & `/alchemy/save-style`）：首中尾多段均衡采样，从 6 大文学维度生成专业文风剖析与 6-8 条创作准则，支持一键存为文风档案；
     2. 资料融汇（`/alchemy/extract-lore` & `/alchemy/import-lore`）：长文智能提炼五大类设定条目与章节大纲树，入库支持同分类同名自动查重跳过；
     3. 开炉炼丹（`/alchemy/brew`）：题材框架、世界观架构、主要人物卡、分卷分章大纲四步结构化推演；
     4. 成丹出炉（`/alchemy/complete`）：支持新建作品或填充现有作品，全套实体、结构化字段与大纲树一键落鼎建书；
     5. 文风档案一键提炼（`POST /works/{id}/style/generate`）。
3. **便签交互防御增强**（✅ 已完成）：
   - 位置：`static/js/pages/bookshelf.js`
   - 实现：便签删除增加确认二次弹窗与 catch toast 异常保护；便签列表加载失败弹出 toast 并提供一键重试占位。
4. **炼丹炉异步长任务系统升级**（✅ 已完成）：
   - 位置：`app/ai_tasks.py`、`app/features.py`、`static/js/pages/alchemy.js`、`static/js/pages/tasks.js`
   - 实现：`/api/alchemy/analyze`、`/api/alchemy/extract-lore`、`/api/alchemy/brew` 接入 `async_mode` 后台任务处理，前端自动轮询并可与任务台账联动，全面解决长任务超时断开与结果丢失痛点。
