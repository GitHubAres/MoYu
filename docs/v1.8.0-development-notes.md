# 墨语 MoYu v1.8.0 开发说明

- **版本号**：v1.8.0
- **更新日期**：2026-10-04
- **构建产物**：`dist/墨语MoYu-v1.8.0-win64.exe`

## 本版新增 / 变更

### 1. 新增「写作工作流」核心模块（三态同页：列表 / 编辑器 / 运行视图）
- **步骤即 Skill 调用**：工作流每个步骤绑定 Skill 市场中的已有技能，复用 `build_skill_system_prompt` 与 `ai_client.chat`，AI 路径零新增多余分支。
- **纯编排薄引擎**（`app/workflow_engine.py`）：
  - 顺序执行工作流各步骤，支持中断恢复与取消。
  - 上下文传递支持 4 种输入来源：本章正文 (`chapter`)、指定前序步骤输出 (`prev_output`)、合并 (`merge`)、无 (`none`)。
  - 支持固定补充指令与 `{{steps.N.output}}` 动态占位符变量替换。
  - 长链路上下文防膨胀保护：超过阈值的前序输出保留头尾各 2000 字并自动标记 `[中段内容已截断]`。
- **人工确认闸一等公民**（`requires_review`）：
  - 标记需确认的步骤完成后自动挂起进入 `awaiting_review` 待确认状态。
  - 提供四大操作：**采纳并继续**（`approve`）、**以修改稿继续**（`edit`，可在内联编辑器精修后推进）、**跳过**（`skip`）、**中止运行**（`abort`）。
  - 后端严格鉴权与状态校验，未确认绝不推进；所有输出只落在运行实例步骤中，绝不静默写入正文。
- **运行视图与台账**：
  - 顶部实时进度条（当前步骤/总步骤）与每步耗时、token 消耗明细。
  - 步骤运行全过程同步记录至 `ai_tasks` 任务台账，支持历史回看与从失败步骤一键重跑（`retry`）。

### 2. 内置示例工作流自动播种
- **章节标准生产流**：生成本章草稿 → 设定一致性检查 → 润色定稿。草稿完成后开启人工确认闸，检查与润色自动衔接。
- **新书开坑五连流**：故事立项 → 世界观设定 → 人物与关系 → 故事大纲 → 首章分场细纲。全流程每个阶段设确认闸，陪伴作者从灵感到细纲。
- 系统启动时幂等播种（`seed_builtin_workflows`），内置工作流受保护不可直接删除，支持一键创建副本编辑。

### 3. Skill 市场扩充与 5 个内置技能播种
- 新增分类与适用任务类型：**立项** (`premise`)、**世界观** (`world`)、**人物** (`cast`)、**细纲** (`scene`)、**全流程** (`forge`)。
- 内置 5 个新规范技能：
  - `novel-premise`：立项·方向定位（灯泡图标）
  - `novel-world`：世界观·规则建构（地球图标，挂载世界观清单参考文档）
  - `novel-cast`：人物·弧光关系（分组图标，挂载人物弧光模型参考文档）
  - `novel-scene`：细纲·分场设计（文档编辑图标，挂载分场节拍参考文档）
  - `novel-forge`：总控·七段流程（枢纽图标，挂载七段创作流程参考文档）
- 更新 `default-analysis` 路由规则，打通与新技能的顺畅联动。

## 改动文件清单

- `app/db.py`：新增 `workflows` / `workflow_steps` / `workflow_runs` / `workflow_run_steps` 四张表及索引；新增 5 个内置技能与参考文件挂载；新增 `seed_builtin_workflows` 播种逻辑
- `app/builtin_skill_data.py`：新增 4 个流程与模型方法论参考常量
- `app/workflow_engine.py`：工作流执行引擎（任务调度、上下文传递、占位符渲染、确认闸、取消与恢复）
- `app/api/workflows.py`：工作流 RESTful API（CRUD、复制、步骤全量替换、启动运行、历史查询、人工确认、取消重试）
- `app/api/__init__.py`：注册 workflows 路由
- `static/js/pages/workflows.js`：工作流前端单页应用（列表态、拖拽排序编辑态、轮询运行与确认视图）
- `static/js/pages/skills.js`：支持新任务类别与对应标签展示
- `static/index.html`：侧边栏新增「写作工作流」入口链接，引入 workflows.js 并更新缓存戳
- `tests/test_workflows.py`：新增 30 项工作流全功能自动化回归测试
- `app/version.py`：升级为 v1.8.0
