# 墨语 MoYu v1.7.8 开发说明

- **版本号**：1.7.8
- **更新日期**：2026-10-04
- **主题**：写作技能选择交互重构 —— 从「精调选项全局下拉」迁移为「任务标签旁按任务绑定」

## 1. 背景与目标

用户反馈「修撰使精调选项」中的「写作技能」下拉菜单可选项少、与任务标签割裂。v1.7.8 将技能选择直接收拢到聊天输入区：选中续写/扩写/缩写/改写任务标签后，在标签右侧菜单中为**该任务**单独绑定技能，默认「自动匹配内置技能」。

## 2. 改动实施

### 2.1 `static/js/pages/workbench.js`

- 移除全局单例 `aiSkillId` 与 `skillSelect` 下拉（`refreshPromptOptions` 一并删除）；
- 新增按任务绑定的 `aiSkillMap`（`localStorage["moyu_task_skill_map"]` 持久化），`skillIdForTask(task)` 读取；
- 新增 `window.aiSkillBridge` 桥接：`listForTask / get / set / syncWindow`，供聊天面板菜单使用；`set` 时同步 `window.aiActiveSkillId`（仅当操作的是当前任务）；
- 「精调选项」设置块移除写作技能行，保留长度/候选分段与「管理技能 →」链接，提示文案改为「技能在输入框上方任务标签右侧按任务选择」；
- 经典多候选面板生成请求 `skill_id` 改由 `skillIdForTask(aiTask)` 提供；经典任务分段切换与聊天「重试」均调用 `bridge.syncWindow` 保持同步。

### 2.2 `static/js/pages/workbench_chat.js`

- 任务标签条右侧新增技能菜单按钮（tune 图标 + 当前技能名/「自动」），点击向上弹出菜单：「自动匹配内置技能（推荐）」+ 当前任务可用技能列表（`applies_to` 匹配或通用），单选勾选态，选择即绑定并记忆；
- `setActiveTask` 切换任务时同步刷新菜单标签与 `window.aiActiveSkillId`；
- 菜单每次打开实时重建列表（Skill 市场增删技能后立即可见）；点击外部自动关闭，页面销毁后监听器自清理；
- 任务标签条由 `overflow-x-auto` 改为 `flex-wrap`，避免向上弹出的菜单被裁剪。

### 2.3 图标字体清单

- `scripts/icons_subset_text.txt` 补登 `keyboard_arrow_down / keyboard_arrow_up / radio_button_unchecked`（woff2 子集字体实际已含这些字形，清单补齐以保证未来重建字体不丢失）。

### 2.4 版本与文档

- `app/version.py`：1.7.7 → 1.7.8；`tests/test_deploy_and_env.py` 断言同步；
- `static/index.html`：`workbench_chat.js` 戳 `?v=1.7.8`、`workbench.js` 戳 `?v=1.7.8`；
- `AGENTS.md`、`README.md`、`docs/PRD-本地版.md` 版本号与技能选择交互描述同步；README 更新表新增 v1.7.8 行；
- 新增本文档。

## 3. 测试回归

- `python -m pytest -q`：105 项全绿（本次为纯前端交互改动，无 API 变更）；
- 实机验证：隔离数据目录 + 8322 端口 + 模拟 AI 服务，验证技能菜单弹出/绑定/记忆、思考过程面板联动、生成链路正常。

## 4. 改动边界与已知问题

- 纯前端改动；后端 `/api/chat` 的 `skill_id` 语义不变（null = 按任务自动匹配）；
- 技能绑定存于 localStorage，换设备/清缓存后回到自动匹配；
- 经典多候选面板不再有独立的技能下拉，跟随当前任务的绑定（与聊天模式一致）。
