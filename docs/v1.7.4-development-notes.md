# 墨语 MoYu v1.7.4 开发进展说明与发布记录

> **版本**：v1.7.4  
> **更新日期**：2026-10-03  
> **性质**：WebView2 桌面端体验修复补丁 (Patch Release)

---

## 1. 修复背景与问题定位

在 `MoYu-v1.7.3-win64.exe` 实机测试中发现两项桌面端体验缺陷：

1. **鼠标滚轮无法上下滚动**
   - 现象：页面只能通过按住鼠标拖动来滚动，滚轮滑动无效。
   - 根因：`static/css/app.css` 中 `html, body { overflow-x: hidden; }` 与 `body { overscroll-behavior: none; }` 同时作用于 WebView2/Edge 内核时，触发渲染引擎已知缺陷，导致原生鼠标滚轮事件被吞掉。

2. **顶部大标题文字顶部被裁切**
   - 现象：如「系统偏好与创作者设置」等页面级大标题，顶部字墨显示不全。
   - 根因：大标题统一使用 `text-display`（40px / 52px 行高），配合 Noto Serif SC 衬线字体在 WebView2 中实际字墨会略超出 line box，导致顶部被裁切。

---

## 2. 修复实施

### 2.1 恢复滚轮滚动

- `static/css/app.css`
  - 将横向溢出控制从 `html, body` 改为仅 `html`：
    ```css
    html { overflow-x: hidden; }
    body { overflow-x: visible; }
    ```
  - 将 `body { overscroll-behavior: none; }` 限定在触控设备：
    ```css
    @media (hover: none) and (pointer: coarse) {
      body { overscroll-behavior: none; }
    }
    ```

### 2.2 修复标题裁切

- `static/index.html`
  - 将 `--text-display--line-height` 从 `52px` 提升至 `56px`（1.4 倍行高）。
- `static/css/app.css`
  - 为大标题增加极小的顶部内边距：
    ```css
    .font-display.text-display { padding-top: 0.05em; }
    ```

### 2.3 版本与文档同步

- `app/version.py`：`1.7.3` → `1.7.4`
- `static/index.html`：`skills.js` / `settings.js` 缓存戳改为 `?v=1.7.4`
- `tests/test_deploy_and_env.py`：版本断言同步为 `1.7.4`
- `AGENTS.md`、`README.md`、`docs/PRD-本地版.md`：所有版本号引用同步为 `1.7.4`
- 新增本文档 `docs/v1.7.4-development-notes.md`
