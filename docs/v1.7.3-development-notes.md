# 墨语 MoYu v1.7.3 开发进展说明与发布记录

> **版本**：v1.7.3  
> **更新日期**：2026-10-03  
> **性质**：全仓编码纯净化与鲁棒性增强补丁 (Patch Release)  

---

## 1. 核心修复背景与问题定位

在对桌面原生版 `MoYu-v1.7.2-win64.exe` 实施深度实机检查过程中，虽然前端主视图与正常创作链路 100% 正常，但发现后端 AI 异常分支中隐藏着 26 处 `????` 乱码占位符：

1. **后端 AI 错误分支文案受损**：
   - `app/ai_client.py`：在处理 401（Key 过期）、404（不支持模型接口）、>=400 服务商报错、500 异常截断以及模块 docstring 中存在 24 处 `????` 乱码；
   - `app/features.py`：第 346 行未配置 AI 接口时的友好提示包含 2 处 `????`。
   - **危害**：当用户在网络波动或配置有误时，后端向前端返回的 JSON 报错文本包含连缀问号（例如 `"message": "API Key ???????401?"`），从而直接在前端 Toast 中暴露乱码。
2. **测试文件注释受损**：
   - `tests/test_ai_models.py` 中包含 39 处测试用例文档字符串与注释乱码。
3. **接口规范与交互优化**：
   - 缺少直接的 `/api/version` 路由别名（此前仅有 `/api/health` 携带版本号）；
   - 前端 Skill 标识名（`name`）命名受强正则限制（禁止下划线 `_`），前端表单缺乏前置校验与友好指引。

---

## 2. 修复实施与长效守护

1. **后端代码纯净化重构**：
   - 全面恢复 `app/ai_client.py` 为纯净标准 UTF-8（无 BOM），规范重写所有异常提示信息（401、404、500、超时及截断文案）与内部注释；
   - 修复 `app/features.py` 中的未配置 AI 提示文案。
2. **测试套件规范恢复**：
   - 彻底修复 `tests/test_ai_models.py` 中所有文档字符串、分步测试说明与断言注释。
3. **长效防损机制升级**：
   - 将 `tests/test_frontend_encoding.py` 升级扩展为全仓编码守护，范围覆盖 `app/`、`static/` 及 `tests/`，断言严禁任何 Python 或前端资源出现连续乱码问号（`????`）。
4. **接口规范与前端防呆**：
   - 在 `app/api/__init__.py` 补充 `@router.get("/version")` 路由，并在 `tests/test_deploy_and_env.py` 中增加断言；
   - 在 `static/js/pages/skills.js` 中增加客户端正则前置校验与输入提示文案（明确告知不可使用下划线）。
5. **版本升级与验证**：
   - `app/version.py` 升级至 `1.7.3`；
   - 自动化测试用例扩充至 **105 项**，100% 全部通过；
   - 触发 CI 自动化构建 Windows 原生客户端并同步至 VPS 生产环境。
