# 墨语 MoYu v1.7.10 开发说明

- **版本号**：v1.7.10
- **更新日期**：2026-10-04
- **构建产物**：`dist/墨语MoYu-v1.7.10-win64.exe`

## 本版新增 / 变更

### 1. 写作工作台新增「分析」任务
- 任务标签区（续写/扩写/缩写/改写）新增「分析」按钮，对应任务 id `analyze`。
- 走 Skill 机制：后端 `TASK_SKILL_MAP` 映射 `analyze → analysis`，兜底命中新增内置技能 `default-analysis`（分析·十维体检）。
- 按用户指令对作品做十维体检式分析评价：逐维打分附原文证据，输出总分、强弱项、短板与按投入产出比排序的修改建议；**只产出分析报告，不改写正文**（符合"生成 → 预览 → 用户采纳"红线，报告默认不写入正文）。
- 聊天输入区任务标签、技能菜单、消息标签、任务记录筛选、设置页任务级模型覆盖均已同步加入「分析」。

### 2. 内置 Skill 覆盖升级（自动播种覆盖老用户数据）
- **大纲生成·纲举目张**（`default-outline`）：正文覆盖为分层大纲方法论（一句话简介 → 故事核心 → 卷幕纲 → 章纲 + 伏笔回收计划），新增挂载 `references/structure-models.md`。
- **设定检查·脉络稽核**（`default-audit`）：正文覆盖为设定台账交叉比对方法论（带原文引用的问题清单，致命/明显/轻微分级），新增挂载 `references/consistency-taxonomy.md`。
- 覆盖机制：`migrate_and_seed_skills` 启动时 `ON CONFLICT(name) DO UPDATE`，老用户升级后自动生效，无需手动操作。

### 3. 新增内置技能「去AI味·人味还原」（`de-ai-tone`）
- `applies_to = rewrite`，在写作工作台「改写」任务的技能菜单中可选。
- 诊断并移除六类 AI 痕迹，核心手法为提升信息密度与打散对称结构，适用于任何文体；挂载 `references/ai-tone-catalog.md`。

### 4. Skill 参考文档内联容量提升
- `build_skill_system_prompt`：`MAX_SINGLE_REF` 3000 → 12000，`MAX_TOTAL_REF` 6000 → 16000。
- 评分量表（analysis-rubric）、矛盾分类体系等长参考文档可完整内联，不再被截断致残；续写三件套参考库亦可一次性完整装载。

## 改动文件清单
