# 墨语 MoYu v1.7.5 开发进展说明与发布记录

> **版本**：v1.7.5  
> **更新日期**：2026-10-03  
> **性质**：内置写作 Skill 全面升级 + 任务路由历史 bug 修复 (Patch Release)

---

## 1. 更新背景

用户提供四套经过实战打磨的小说创作 Skill 包（novel-continuation 续写 / novel-expansion 扩写 / novel-rewriting 改写 / novel-condensation 缩写），要求替换软件内置的默认写作 Skill，并保证功能覆盖。排查过程中同时发现一个历史 bug：写作工作台的「缩写」「改写」两个任务自 Skill 体系上线以来从未命中过对应技能，实际一直在错误地使用续写技能。

---

## 2. 改动实施

### 2.1 内置 Skill 正文升级（`app/db.py` BUILTIN_SKILLS）

- `default-continue`（续写·顺延文势）：新正文融入文风指纹提取、零复述、有推进、留钩子、控 AI 腔五项准则。
- `default-expand`（扩写·充实细节）：新正文融入信息只增不减、事件不增不减、设定不新增、密度可控、节奏不塌五项准则。
- `default-shorten`（缩写·凝练取舍）：新正文融入零新增、不改动事实与顺序、人名称呼一致、不注水凑字数、保留最有力意象五项准则。
- `default-rewrite`（改写润色·字句打磨）：新正文融入改彻底、残留清零（连续 12 字查重）、不合并任务、不改不该改的、控 AI 腔五项准则。
- 正文为面向 MoYu 单次 API 调用架构的适配压缩版，保留 `{{context}}` / `{{selection}}` / `{{instruction}}` 占位符契约不变。

### 2.2 方法论参考文件入库（新增 `app/builtin_skill_data.py`）

- 将 Skill 包中的 6 份完整方法论文档作为常量沉淀：
  - 续写挂载 `references/style-fingerprint.md`、`references/prose-craft.md`、`references/genre-playbook.md`
  - 扩写挂载 `references/expansion-craft.md`
  - 缩写挂载 `references/compression-formats.md`
  - 改写挂载 `references/rewrite-dimensions.md`
- `migrate_and_seed_skills` 第 2 步升级为：种子 upsert 技能后，同步将 `files` 内容 upsert 进 `skill_files` 表（依赖既有 `UNIQUE(skill_id, path)` 约束，幂等）。
- 沿用既有技能名（`default-continue` 等）复用 `ON CONFLICT(name) DO UPDATE` 机制：老用户升级后启动即自动换血，无需删库。
- 系统提示词装配沿用 `build_skill_system_prompt` 既有 references/ 内联逻辑（单文件 3000 字、总量 6000 字上限自动截断），长文档不会撑爆上下文。

### 2.3 修复缩写/改写任务路由历史 bug

- 现象：前端任务名为 `condense` / `polish`，而技能 `applies_to` 为 `shorten` / `rewrite`，两侧命名不一致导致：
  - 技能下拉框在缩写/改写任务下过滤不出对应内置技能；
  - 未手选技能时后端兜底全部落到 `default-continue`（续写）。
- 修复：
  - `app/features.py` `build_skill_system_prompt` 兜底分支新增 `TASK_SKILL_MAP = {"condense": "shorten", "polish": "rewrite"}` 映射。
  - `static/js/pages/workbench.js` `refreshPromptOptions` 增加同样的映射后再过滤技能列表。
- 聊天模式（workbench_chat.js）复用同一 `skill_id` 与后端兜底函数，随本次修复一并生效，无需额外改动。

### 2.4 版本与文档同步

- `app/version.py`：`1.7.4` → `1.7.5`
- `static/index.html`：`skills.js` / `settings.js` / `workbench.js` 缓存戳改为 `?v=1.7.5`
- `tests/test_deploy_and_env.py`：版本断言同步为 `1.7.5`
- `AGENTS.md`、`README.md`、`docs/PRD-本地版.md`：所有版本号引用同步为 `1.7.5`
- 新增 `app/builtin_skill_data.py` 与本文档 `docs/v1.7.5-development-notes.md`

## 4. 改动边界与已知问题

- 仅替换 4 个写作类内置技能（续写/扩写/缩写/改写），`default-outline`、`default-audit` 保持原样；
